# AI 视频自动剪辑软件 (本地版)

## 特性
- ✅ 适配本地电脑 (CPU运行)
- ✅ 无需GPU
- ✅ 支持多种AI模型
- ✅ 自动提取文案 + 生成脚本
- ✅ 智能定位高潮点
- ✅ 添加BGM/贴纸

## 系统要求
- **操作系统**: Windows 10+, macOS 10.14+, Ubuntu 18.04+
- **Python**: 3.8+
- **内存**: ≥8GB (推荐≥16GB)
- **存储**: ≥5GB可用空间
