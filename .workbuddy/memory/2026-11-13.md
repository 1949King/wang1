## 本轮踩坑（已写进 MEMORY.md 持久约束）
1. QtWebEngine 里不要在事件过滤器里 exec/popup 菜单 → 嵌套事件循环/黑块/假死/崩溃。
2. 可见控件 setParent(None) 会变成顶层窗口（ghost windows），清布局必须先 hide。
3. 整文件 read+write 会被工具单次读取上限截断（App.tsx 1860→1175、help_module 823→776）：
   大文件一律用精准 edit / 行号 splice，改完核对行数与 git diff --stat。
4. WebEngine localStorage 不可信（不持久且不报错）：需要跨重启的状态走后端记账。
