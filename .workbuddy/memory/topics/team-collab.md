# 团队协作深水区（画布 0.3.52，2026-11-12 复核）

> 方案文档：`docs/_reports/2026-11-04-团队协作对标与新版方案.md`。⚠️ 行号会漂，查代码别信旧行号。

## 一、路线结论（对标过三家）

DaVinci / Premiere / CapCut **都不做实时共编**，只有 Figma 做。
视频项目 = 大二进制 + 时间轴强耦合 ⇒ **CRDT 是负资产**。
「**锁 + 冲突检测 + 服务端 diff**」的路线是对的，不要改。

骨架：`push(base_rev)` 冲突不自动合并、`claim` 项目锁 TTL 600、服务端 `diff(from,to)` 只回摘要、
前端 `teamDiff` / `formatTeamDiff`。

## 二、2026-11-04 记的「三个致命空洞」—— 已全部补掉（旧记忆作废）

### (a) `role` 曾是装饰品 → 0.3.52 立真权限
- `owner` / `editor` / `viewer` 三态 + `_need(need)` 守卫，五个写端点要编辑权。
- 同时堵掉一个真洞：`POST /team/join` 曾把请求体里的 `role` **原样写库**
  （任何人 POST `{"role":"owner"}` 即变主人）。
- 现在：忽略请求体角色（首成员 owner、其余 viewer），**编辑权只能来自配对码**；
  `pairing` 表加 `role` 列；改角色属 owner 专属。

### (b) 无批注 → `comment` 表
- `node_id` 挂节点不挂坐标；空串 = 整份画布。
- **提批注不产生新 rev**（否则批注会把版本表刷爆）。
- viewer 能提批注，但不能改解决状态。

### (c) 无 presence → `member.last_seen` + 心跳
- `auth()` 刷新，20 秒节流；老库补列取 **0 不取 now**（否则全体瞬间"在线"）。
- 前端 `teamPresence.ts`，在线窗口 90 秒；12 秒心跳，失败亮红字。
- 原则：**宁可说在线也不谎报离线**。

## 三、0.3.51 收窄配对

- 二维码砍掉（只为它多养 cv2 + `team_qr.py`，不值），只留 **6 位码 + 邀请链接**。
- `/pair?code=` 落地页保留。
- 新增 `teamInvite.ts`：`parseInvite()` 认纯码 / 带码链接 / 光地址，**不联网不猜**。
- 链接带地址走 `joinByLink()` 直接换令牌、**不发 UDP** —— 这是跨网段唯一通路。

## 五、仍存隐患（未解）

3. `diff` 只比结构不比素材。
