## Qt6 编辑器三处 Bug 修复 ✅

文件：`app/modules/lego/editor_module.py`

### 1. AI字幕报错 `name 'sys' is not defined` + 贴纸无反应（同一根因）
- **根因**：第17行 `import sys as _sys`，但全文件 18 处使用 `sys.platform`（未定义名字）。一旦调用 ffmpeg 就 `NameError`。AI字幕(2749行)、贴纸(6477行) 都走 ffmpeg → 后台线程崩溃。
- **修复**：第17行改为 `import sys`；第171-172行 `_sys.path` → `sys.path`。
- **贴纸额外修复**：后台线程里直接 `QMessageBox` 不安全（静默失败→"没反应"），改用 `QTimer.singleShot(0, ...)` 把完成/失败提示派发回主线程。

### 2. 滤镜/调节"显示正常但画面没变化"
- **根因**：预览区用 `QMediaPlayer` 播放原片（`_video_widget`），滤镜只写进 `clip.effects` 元数据；`PreviewManager` 渲染的滤镜帧被发到**隐藏的** `_preview_label`，且 `_apply_effects` 不认识滤镜名（"电影感"等字符串）。
- **修复**：重写 `_refresh_preview_with_effects`：
  - 新增类属性 `_FILTER_PREVIEW_PARAMS`：11个滤镜名 → 数值参数（对齐 `PreviewManager._apply_effects` 支持的键：contrast/saturation/hue/blur/vignette/sharpen/brightness 等）。
  - 应用滤镜时隐藏 `_video_widget`、显示 `_preview_label`，用 `PreviewManager` 实时渲染滤镜帧；清除后恢复。
  - 缓存 `_last_render_params` 供 seek（快进/快退）同步。
  - `_play_pause` 播放时改用 `_playhead_position` 保证时间轴一致。

### 3. `_get_ffmpeg` 冗余增强
- 新增 venv `Scripts/ffmpeg.exe` 查找路径（实际 thirdparty 目录已有 ffmpeg，此项为冗余保险）。

### 验证

## 贴纸预览与滤镜播放优化（V4.9.2）✅

### 问题1：贴纸渲染后视频不更新
- **根因**：贴纸渲染成功后只调 `_add_to_clips` 加入素材列表，QMediaPlayer 仍播原片，用户看不到变化。
- **修复**：渲染完成后用 `QTimer.singleShot(0, ...)` 在主线程将结果视频加载到 QMediaPlayer（`setSource` + `setPosition(0)`），并切回 `_video_widget` 显示。

### 问题2：切换滤镜后播放卡顿
- **根因**：滤镜激活时 `_refresh_preview_with_effects` 把预览切到 `PreviewManager`（OpenCV CPU 逐帧解码 + numpy 效果），720p/1080p 无法实时 → 严重卡顿。
- **修复策略 — 分策略预览**：
  - **暂停/拖拽时** → PreviewManager 精确渲染滤镜帧（用户可见效果）
  - **播放时** → 切回 QMediaPlayer 硬件加速流畅播放（滤镜效果在导出时烘焙）
  - `_play_pause`：暂停后调 `_refresh_preview_with_effects` 切到滤镜预览；播放前若有滤镜则切回 QMediaPlayer
  - `_rewind`/`_fast_forward`/进度条拖拽释放 → 统一走 `_refresh_preview_with_effects`
- 版本同步：version.py → V4.9.2，CHANGELOG.md 新增条目。
