# 拾光剪影 项目重构改进计划

## Context（为什么做这件事）

项目评价发现 4 类工程问题：
1. **巨型文件失控**：`editor_module.py` 10,087 行，占项目 6.9%，违反单一职责
2. **静默异常泛滥**：263 处 `except...pass`，错误被吞，调试困难
3. **测试散乱**：测试文件散落在 `app/test_*.py`、`app/temp/verify_*.py`，无统一组织
4. **重复目录**：`render/`、`utils/`、`video_editor/` 多套并存，多为孤儿

用户要求"全都要"改进。本计划按**风险递增**分 5 阶段执行，每阶段可独立验证、可回退。

## 关键约束（项目铁律）

- **不删原有代码、不破坏功能、不新增无用文件**
- **冻结区 21 个符号绝对不动**（playback-av / exit-media / canvas-transform 三区）
- 拆分采用 **Mixin 模式**（方法签名/调用不变，仅移动实现），最小入侵
- 每阶段必须通过 `py_compile` + `frozen_zone_guard.py` 验证

## 探查事实（决策依据）

### editor_module.py 拆分依据
- 10,087 行，374 方法，主类 `EditorModule(BaseModule)`（L263）
- 冻结符号 21 个：`_play_pause`/`_start_timeline_playback`/`_on_position_changed`/`eventFilter`/`_preview_norm_from_pos` 等
- 外部导入仅 5 处（全在测试文件），主程序经 `module_registry` 懒加载 → 接口不变则零影响
- 3 个非冻结高内聚块：
  - **Agent 面板 + Pipeline 精剪**（L8265-9635，约 1370 行）
  - **AI 工具面板**（L5130-6200，约 1070 行）
  - **贴纸系统**（L8090-8265，约 175 行）

### 静默异常分布
- Agent 闭环 10 文件仅 4 处（优先清理）
- 主战场：`app/core/` 其他文件 + `app/modules/lego/` 文件

### 重复目录
- `app/modules/lego/render/`、`app/modules/render/`、`app/utils/`、`app/modules/utils/`、`app/modules/lego/utils/`、`app/modules/lego/video_editor/` 全部 0 次外部导入（孤儿或仅内部相对导入）

## 阶段 3：静默异常清理（中风险，P0）

**目标**：263 处 `except...pass` 改为带日志的异常处理

**策略**：分批清理，每批验证
- **批次 A**：Agent 闭环 10 文件（4 处，已在阶段 1 处理）
- **批次 B**：`app/core/` 其他文件（约 100 处）
- **批次 C**：`app/modules/lego/` 文件（约 100 处）
- **批次 D**：`app/plugins/` 文件（约 50 处）

**改动模式**：
```python
# 改前
except Exception:
    pass
# 改后
except Exception as e:
    logger.warning(f"[模块名] 操作失败: {e}")
```

**约束**：
- 不改变异常捕获范围（不缩小也不扩大）
- 不改变控制流（except 块仍不抛出新异常）
- 仅添加日志记录，保持原有"容错继续运行"语义

**验证**：
- 每批次 `py_compile` + `frozen_zone_guard.py`
- 启动应用确认无新报错

## 阶段 4：editor_module.py 拆分（高风险，P0，分 3 子阶段）

**目标**：10,087 行 → 约 7,500 行，拆出 3 个 Mixin 文件

**技术方案：Mixin 模式**
```python

class EditorAgentMixin:
    """EditorModule 的 Agent 面板 + Pipeline 精剪 Mixin"""
    def _create_edit_agent_panel(self): ...  # 方法体原样搬移
    def _apply_multi_clip_ffmpeg(self, ...): ...

# editor_module.py 改动（仅 2 行）
from .editor_agent_mixin import EditorAgentMixin
class EditorModule(BaseModule, EditorAgentMixin):  # 加 Mixin 继承
    ...
```

**子阶段 4a：拆出 Agent 面板 + Pipeline 精剪**（L8265-9635，约 1370 行）

- **验证**：`frozen_zone_guard.py` + 启动应用 + 打开 Agent 面板测试

**子阶段 4b：拆出 AI 工具面板**（L5130-6200，约 1070 行）
