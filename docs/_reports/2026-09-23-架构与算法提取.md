## 三、算法与公式提取

### 3.1 内容情绪 8 维向量（真身）

- 定义 `drama_understanding_engine.py:541-542`：`EMOTION_DIMS = [开心, 悲伤, 愤怒, 紧张, 浪漫, 悬疑, 激动, 温馨]`，每维 0-1
- 归一化 `:675-679`：`vec = vec / vec.sum()`（无命中取均匀 0.125，`:646-647`）
- 音频侧同构 `audio_emotion_analyzer.py:40`（保证两路可对位融合）
- ⚠️ 常见误认：`affect_model.py` 不是内容情绪，是 **Agent 内心状态**（见 3.10）

### 3.2 ABCD 四维融合矩阵（真高光算法）

- 位置：`drama_understanding_engine.py:1429-1691`
- 维度：A=剧情 B=情绪 C=视觉 D=爆款；**权重按剧种 8 套**，如甜宠 `{A:0.20, B:0.45, C:0.20, D:0.15}`（`:1433`），默认 `{A:0.25,B:0.30,C:0.25,D:0.20}`（`:1442`）
- 时间轴 0.5s 网格（`:1460`）：
  - A 轴 `score = importance × emotional_impact`（`:1470`）
  - B 轴 `b_score = 0.40·arousal + 0.40·intensity + 0.20·volatility`（`:1506`），其中 `arousal=Σvec[2,3,6]`、`volatility = 1−(top1−top2)/top1`（`:1495-1503`），加局部反差 `(1−cos(pre,post))×0.3`（`:1515-1517`）
  - C 轴按场景类型查表（CONFLICT 0.9 / ACTION 0.85，`:1546-1551`）
  - D 轴 = viral_detector 的 `total_score/100`（`:1576-1586`）
- **融合** `fused(t) = wA·A(t)+wB·B(t)+wC·C(t)+wD·D(t)`（`:1597-1605`）→ 阈值 0.35 / 3~30s 连续高分区（`:1608-1649`）→ 间隔 <3s 合并、贪心控总时长（`:1651-1691`）
- 剧种识别：余弦相似度 + 样本修正 `sim × min(1, sample_count/20+0.5)`（`content_classifier.py:242-251, 327`）

### 3.3 多模态情绪融合（文本+音频）

`drama_understanding_engine.py:1157-1166`：`fused_vec = tv×0.55 + av×0.45`，再归一；无音频退化为 tv。
音频特征映射 `audio_emotion_analyzer.py:44-58`（RMS/质心/过零率/F0 → 8 维权重的启发式表），门控 sigmoid `1/(1+exp(-8(v-0.5)))`（`:281`）。

### 3.4 LLM 优先 + 关键词降级

### 3.11 画布磁吸算法五件套

**① edge-gap 判据**（`MagneticEngine.ts:61-70`）：
```ts
gapX = max(a.x − (b.x+b.w), b.x − (a.x+a.w), 0)
gapY = max(a.y − (b.y+b.h), b.y − (a.y+a.h), 0)
gap  = hypot(gapX, gapY)
```
分档（`types.ts:66-78` DEFAULT_MAG_CONFIG）：gap<10 instant / <60 strong / <50 medium / ≤120 weak；吸合落点 `gap=−2`（边框融合，`MagneticEngine.ts:225, 243-265`）。

**② Bond 咬合**（`bonds.ts`）：无向键 `a<b ? a|b : b|a`（`:28-30`）；形成条件 = 边距 ≤2px 且投影重叠 ≥40px（`:25, 66-79`）；**纯几何推导无状态**，断裂自然消失；多咬合按拖拽方向点积选最相关（`:154-176`）。

**③ 三段式手感**（`useMagneticDrag.ts:277-309`）——最有特色：
```ts
pull = hypot(pullX, pullY)
give = pull ≤ 30 ? 0                          // 段1：纹丝不动
     : (pull − 30) × 0.28                     // 段2：只让出 28%
strain = min(pull / 50, 1)                    // 张力进度
pull ≥ 50 → 断裂 + 本次拖拽屏蔽回吸             // 段3：脆断
```
视觉佐证：SnapSeam `grow = strain×13`、线宽 `3 → 1.5`（`SnapSeam.tsx:110-111`）。

**④ reflow 让位**（`reflow.ts:156-330`）：同行判据 重叠≥40px；步进 `step = 卡尺寸 − 2px`（`:130-133`）；链式吸收「同行+同侧+间隙≤2px」的紧邻卡（`:248-276`）；链尾平移后撞链外卡 ⇒ `blocked: true` 整链放弃（`:289-304`）。

**⑤ 拖拽状态机**（`useMagneticDrag.ts`）：拖拽全程 1:1 跟手不覆写（`:326-336`）→ 松手邻居先滑开 180ms → 拖拽卡滑入 ghost，200ms + strong/instant 带 **5px 过冲再弹回**（`:421-431`）；动画曲线 easeInOutCubic `t<0.5 ? 4t³ : 1−(−2t+2)³/2`（`:142-153`）。

**磁吸层级** `magneticLevels.ts:97-107`：`gap<0 none / <10 instant / <60 strong / <50 medium / ≤120 weak`；**strength 自 2026-09-18 起只做 UI 展示，不再驱动吸附力度**（`:26`）。

### 3.17 双记忆模型

- **观众记忆**（`memory_model.py`）：`λ = λ0·(1−0.6E)·(1−0.5C)·(1+0.8I)`；`R(t) = R0·e^(−λt)`；λ0 细节 0.090 / 意义 0.020 / 情绪 0.008（/小时）；综合分 `(0.2D+0.45S+0.35E)×(0.5+0.5R)`
- **系统经验**（`memory_store.py:142-185`）：`strength = score·e^(−λt)`，λ0=0.001/小时（比观众小两个数量级）；`C = min(recall_count/饱和值, 1)` 用得越多忘得越慢

### 3.18 故事板时长分配（storyboard_memory.py）

24h 保留率基线：细节 11.5% / 意义 61.9% / 情绪 82.5%；按保留率权重分配总时长 `out[i] = total×w[i]/Σw`，迭代 ≤8 轮夹紧 `[0.8s, 12.0s]` 并摊余（`:92-130`）；**相邻双情绪锚点或 ≥4 镜且情绪镜过半 → 警告「名场面太多反而记不住」**（`:186-198`）。
