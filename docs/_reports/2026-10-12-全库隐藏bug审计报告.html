五、审计方法注记（防复踩）

  • 网络 timeout 检查必须按接收者过滤：按函数名匹配 post/get/put/delete/request 会命中全部字典 .get() —— 7056 条假阳性洪水；正确做法 = AST 只认 requests.X(...)（Attribute.value 是 requests 别名）、urllib.request.urlopen Attribute 链、以及经 ImportFrom 追踪的 from requests import post 直呼。
  • open 检查必须用 AST 裸 Name：子串匹配会把 subprocess.Popen(、Image.open(、webbrowser.open(、av.open(、sdk.open(、_ensure_preview_source_open( 全算进去 —— 269 条假阳性；AST 化后剩 5 条真命中。
  • isinstance 检查必须核 import 来源：名字叫 Mapping 不等于来自 typing —— collections.abc.Mapping 是完全正确的写法。
  • dup_method 必须区分 deco_kind：@x.setter 是 ast.Attribute 无 .id，与 @property 配对不是重复定义。
