## 2. 节点与运行时许可红线（对我们安装包的含义）

- **GPL-3.0 不随包**：ComfyUI 本体、KJNodes、Goohaitools、hyperflow int8/Flash、Idol。上游姿态是「只通过 HTTP API 调用，不含源码/二进制」——我们若接 ComfyUI，沿用同姿态，**不把这些节点/二进制打进拾光剪影安装包**。
- **授权链不完整不随包**：TE_MAN（上游禁止再分发，上游凭作者书面授权随包，**该授权不覆盖我们**）、TE-Speed-MOSS、TE-Speed-MiniMaxH3、SelfLift（均无 LICENSE）。
- **可随包（MIT/Apache）**：ComfyUI-Florence2、llama-cpp_vllm、llama-cpp-python 预编译、SeedVR2 节点、comfystreamerh3、ClipProj、SolAttn_triton。

## 3. 显存与硬件口径

- 上游端到端验证环境：Windows + RTX 4080 SUPER（README 原文称 32GB）。
- **无单工作流显存数字** [UNKNOWN]；int8/FP8/W4A8 量化 + SageAttention 是其省显存路径；H3 视频/超分预期高显存 [INFERRED]，选型时必须本机实测。
- 我们侧保留 `GPUDetector`/fallback 纪律；低显存兜底不引入云依赖（上游的云电脑推荐仅作背景信息）。

## 4. 商用选型速判（参赛/商业交付口径）

- **优先池（Apache-2.0/BSD/MIT）**：Qwen3.5-9B GGUF、SeedVR2 权重+节点、RealESRGAN、Idol UNet/VAE、Florence-2 PromptGen、Qwen3-VL-4B FP8、SageAttention。
