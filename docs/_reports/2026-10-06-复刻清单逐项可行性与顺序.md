## 1. LibTV 三件（智能引用 / 片段重拍 / 超长视频）

### 1.1 智能引用 ✅ 已完成
已按**真实通道**实现（上游那种「往提示词塞 @ 名字」是装饰，模型读不到）。
**待加强（可选）**：支持"多条上游按顺序全部引用"（现在是取第一条有效边）—— 需要模型侧支持多参考图，**取决于渠道能力**，要单测确认后再做。

### 1.2 片段重拍（指定时间段局部重生成）—— **可做，中工作量** ⭐
**做法**：以「原片 + 目标时间段 + 新提示词」为输入 →
① 用 ffmpeg 精确切出上下文（前留 0.5s 尾巴接续）→ ② 重生成该段 → ③ 用 ffmpeg **只替换该时间段**并保持音轨（`concat` + 时间轴对齐）→ ④ 输出与原片同规格。
**难点（必须诚实说）**：**接缝**。生成段的色调/运动连续性来自不同的一次推理，边界可能跳。
**缓解**：① 把切点放在**镜头切换处**（检测场景变化）；② 用原片**尾帧作为新段的参考首帧**（我们已有能力）；③ 输出时如实标注「接缝在 xx 秒，建议检查」。
**依赖**：`ffmpeg_utils`（已有）+ 视频生成能力（已有）+ 场景检测（需补：`ffmpeg` 的 `select='gt(scene,0.3)'`，很便宜）。

### 1.3 超长视频（30s → 多分钟，保留分镜节点）—— **可做，大工作量**
**做法**：把「长片」拆成**分镜节点序列**，逐个生成后按时间线拼接；关键是**跨段一致性**（角色/光线）。
**我们其实更接近这个形态**（我们本是剪辑底座 + 分镜节点）⇒ 真正缺的是：**自动分段 → 逐段生成 → 自动拼接入时间线**这一条流水线。
**依赖**：片段重拍（1.2）做完后，1.3 只是它的"批量版" ⇒ **建议 1.2 → 1.3 顺序做**。

## 6. 逐帧拉片 / 爆款复刻 —— **可做，中** ⭐（你说"别人做不到"的那条）

**上游**：把参考片拆成结构化脚本（时长 / 景别 / 机位 / 运镜 / 光线 / 声音 + 替换方案）。
**我们有的零件**：**深度提取（刚做）** + 姿势/骨架 + `cameraRecorder` + 场景检测（ffmpeg）+ 多模态模型（可看图）+ 分镜数据模型。
**做法（拆成三级，逐级加码）**：
- **L1 结构级**：ffmpeg 场景切分 → 每段时长/关键帧 → 关键帧交给多模态模型描述（景别/主体/光线）⇒ **产出结构化镜头表**，可直接落到分镜节点。**成本低、当天可出**。
- **L2 运动级**：对每段跑**深度/姿势**，得到运镜与运动描述（推/拉/摇/跟）⇒ 更接近"运镜复刻"。
- **L3 复刻级**：把 L1+L2 结果变成**可执行的分镜节点序列**（含替换方案：换角色/换场景），一键生成。
**为什么说别人做不到**：这需要**同时又懂"拆"（多模态 + 深度/姿势）和"拼"（时间线剪辑底座）** ——
一般 AI 视频工具只有前半段（拆）或后半段（拼），**我们两段都在自己手里**。

**依赖**：既有 `stage3dPoseRetarget` ✓ 所以是**续刀**而不是重做。

## 8. 3D 场景粗搭（场景/背景/配角模型）—— **可做，大**

**上游对照**：LibTV 3D-BOX（3D 视角框）；TapNow Cinema Lab（3D 空间 + 影棚布光）。
**三级做法**：
- **L1 粗搭（推荐先做）**：从**现成图**生成 3D 体块 —— ① 用深度图（**我们刚做的能力**）把场景图"立起来"：前景/中景/背景**分层**成 2~3 个深度平面 → 视差移动即有 3D 感；② 配角用**简单基元**（人体盒/胶囊）摆位标定。
- **L2 半自动建模**：接 **Blender MCP**（我们通道已通）做低模生成/摆放。
- **L3 真建模**：接文生 3D（成本与质量另说）。
**关键判断**：**L1 就能达成"粗搭场景 + 配角占位"的效果**，而且**复用刚做的深度能力**，性价比最高。
