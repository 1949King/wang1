## 一、上游架构与执行管线（深读基础）

三层：`infinite-canvas/web`（React 19 + three 0.186 + zustand + antd 前端）→ `comfyui-gateway`（Node.js，:8190，把工作流暴露成 OpenAI 兼容 `/v1/*`）→ ComfyUI（:8188，launcher 接管）。

**网关执行链**（`comfyui-gateway/src/`）：
- `server.js`（≈199KB）：路由总入口。`/v1/images/generations`、`/v1/images/edits`（:2401）、`/v1/videos`（:2737 起）、`/v1/videos/upscale`（:2629）、`/v1/videos/interpolate`（:2737）、`/v1/scene3d/*`（:2126）、`/v1/3d/generations`（:2279）、`/v1/jobs/:id/preview`（SSE）。

- `bindings.js`：`applyBindings` 把用户参数写进工作流节点；**动态注入** `LoadImage/LoadVideo/LoadAudio` 节点（id 从 9101 递增，:103-141）；`frameMode` first/last/both 决定首尾帧挂哪个输入（:143-160）；数组参考 `ref_images[]/ref_videos[]/ref_audios[]` 按 `inputPrefix` 批量注入（:162-196）；变换器 `snap32`（32 对齐）、`secondsToFrames17`（帧数=17k+5，@24fps，:236-247）、`qwenSigmas`（sigma 表插值）。
- `runner.js:128` `runWorkflow`：`applyBindings`→`applyModelAliases`（模型别名替换，:39）→`comfy.submit`（POST /prompt，`previewEnabled`）→轮询 `/history`（750ms）→`collectOutputFiles`（:110，只收 type=output，可选 temp 预览）。
- `preview-hub.js`：ComfyUI WebSocket 二进制帧（type 1=JPEG 预览）→环形缓冲 8 帧→SSE `/v1/jobs/:id/preview`，250ms 节流。**采样预览的传输层**。

## 二、五能力上游实现原理

### 2.1 视频编辑（剪辑/拼接/首尾帧/多参考生视频）

**A. 多参考生视频 = H3 Ref2VA**（registry id `video-h3-ref2va`→`workflows/h3-ref2va-drama-vdn.json`；`video-h3-ref2va-novdn`→`h3-ref2va-drama.json`）

条件节点 `76 MiniMaxH3AudioConditioningT8`（vdn 版）输入：`task_type="Ref2VA"`、`audio_mode="native"`、`reference_video_policy="official_2_to_15s"`、`ref_image_size="match"`，以及 `first_frame / last_frame / ref_images / ref_videos / ref_audios`。registry 绑定：`74`=steps（默认 8）、`78`=SelfLift 采样器（seed/cfg/transition_step=6/lowres_scale=0.6/rho=0/w_min=0.3/w_max=1）、length=`secondsToFrames17`（默认 124 帧）、width=`snap32`（默认 1344）、height=768。

vdn 节点链：`UNETLoader(minimax-h3_Singularity_ref2va_Pruned_v1.3_int8)` → `ApplyVDNH3Advanced`（vdn_checkpoint=stage-dmd-step-250、turbo adapter、attention_backend=grouped、window_radius=1、window_chunk=5、anchor_frames=both）→ `MiniMaxH3MemoryEfficientSageAttentionPatch` → `MiniMaxChunkFeedForward`（chunks=2、seq_threshold=4096，分块 FFN 省显存）→ `ModelPreviewOverrideKJ`（见 §2.5）→ `BasicScheduler(simple,8)` → `SelfLiftH3Sampler` → `MiniMaxH3AVDecodeT8`（**TRT VAE**：`MiniMaxH3TRTVAELoader` 加载 `.engine` TensorRT 引擎）→ `VHS_VideoCombine`（h264-mp4、crf22、24fps、**带音频**）。

novdn 节点链差异：`LoraLoaderBypassModelOnly`（LightX2V FL2V Turbo 8step 768p bf16，绕过量化模型的 LoRA 加载）→ `ModelAttentionBackend("comfy kitchen attention")` → `SolAttnPatch`（tau=1.3、start=0.2、end=0.9、min_tokens=12288、**int8_qk=true、int8_pv=true**，稀疏注意力）→ `MiniMaxH3SigmaShift`（shift_video=12、shift_audio=3）→ `H3SigmaRefiner`（extra_steps=1、0.7→0、cosine，尾段补精修步）。
⚠️ **`TESpeedMiniMaxH3`（节点 110）在两个 drama 变体里都定义了但未接进主链**（model 走 4→32→71→27→111）——不要误判为已启用。

**B. 网关 mode 路由**（`server.js:2838-2930`）：H3 三模式 `text/frames/reference`。text 拒收任何素材；frames 只收 1–2 图（`frameMode` first/last/both，both 需 2 图）；reference 至少 1 个图/视频/音频。Viggle 视频编辑（`video-h3-viggle-swap` edit 模式）= 1 段源视频 + 1–4 张「抽帧→图像编辑改好→回传」的参考图（`pins` 填帧号，:2917）；`ensureSourceAudio` 给无音轨源片补静音轨（:2935）、`fitViggleSourceCanvas` 短边 480 防拉伸（:2940）、`flattenViggleReferences` 透明图压背景色（:2948）。

**C. 剪辑/拼接（trim/concat）——上游也未接线**：前端 `infinite-canvas/web/src/components/canvas/canvas-video-edit-modal.tsx` 有片段 inPoint/outPoint 双滑块裁剪 + 拖动排序 + 顺序预览，但 **:226 明写「导出待接网关：当前试做只提供顺序预览与字幕编辑；视频 trim/concat 需要网关 ffmpeg 路由，未生成假文件」**。`services/api/video-edit.ts` 只有 Phase1 `/video-edit/preview` 契约（swap/edit，frame+mask+ref）。**结论：画布侧真 trim/concat 上游也是半成品，不必追。** `[已核]`

**D. 补帧 = RIFE**（`/v1/videos/interpolate`，`server.js:2737`；`workflows/_internal/video-rife.json`）：`LoadVideo`→`GetVideoComponents`→`RIFE VFI`（ckpt=rife49.pth、multiplier、ensemble、scale）→`CreateVideo`（**音频=源[1]、fps=源 fps×multiplier**）→`SaveVideo`。`video-interpolation.js:20` 用 ffprobe 读源 fps。

**E. 音频保留通式**：所有视频工作流都用 `GetVideoComponents` 拆出 images[0]/audio[1]/fps[2]，处理完 `CreateVideo` 把 audio[1] 原样接回——**这是上游视频处理不丢音频的统一手法**。

依赖/许可：H3 权重=社区重打包（ModelScope Comfy-Org/MiniMax-H3，**MiniMax H3 Community License，条款未读**，MEMORY.md:57）；KJNodes/VHS=GPL（HTTP only）；TRT VAE 需 TensorRT `[UNKNOWN 部署代价]`。

### 2.2 局部修改（inpaint / 真蒙版重绘 / 移除 / 扩图）

**入口**：`/v1/images/edits`（`server.js:2401`）。`mode=inpaint/remove` **必须 2 个文件**（原图 + 二值蒙版，:2448-2453）；`mode=outpaint` 单图 + `megapixels`（上限 `config.outpaintMaxMegapixels`）；`singleShot` 强制 count=1。

**inpaint 节点链**（`workflows/image-qwen21v2-inpaint.json`）：
`9101 LoadImage(源)` + `9102 LoadImage(蒙版)` → `ImageToMask(channel=red)` → `GH_MaskCropV2`（Goohaitools，按蒙版裁切，expand=1.3/1.4，输出 seam 信息[0]/裁切图[1]/裁切蒙版[2]）→ `图像缩放范围孤海`（长边限 768–2048、÷32）→ `图像缩放V2_孤海`（lanczos、stretch）→ `TextEncodeQwenImage21GH(mode="填充")`（编码图+latent 尺寸→conditioning+latent[2]）→ `UNETLoader(qwen_image_2.1_turbo_int8_convrot)` + `LoraLoader(一致性无偏移,0.48)` → `ManualSigmas`（9 步 sigma 表）→ `SamplerCustomAdvanced(euler)` + `BasicGuider`（无 CFG）→ `VAEDecode` → `GH_CropRestore`（按 seam 回贴，mask_expand=4%、feather=5%、color_restore=1）→ `SaveImage`。
**原理要点**：不是整图重绘——先按蒙版裁切放大到模型最优分辨率重绘，再羽化回贴原图，接缝由 GH_CropRestore 处理。

**remove**（`image-qwen21v2-remove.json`）：同链，但在裁切图上叠 `GulfSeaImageMergeMask`（**绿色 #00ff00、opacity 0.4**）盖住蒙版区，prompt=「移除图像中的绿色区域」，LoRA 换 `万物移除` 强度 1.0。**绿幕 trick + 专用移除 LoRA** 实现语义移除。

**outpaint**（`image-qwen21v2-outpaint.json`）：`图像外扩孤海`（left/right/top/bottom 像素外扩）→缩放→`TextEncodeQwenImage21GH(mode="扩图")`→同 turbo-int8 + 一致性无偏移 0.48 → 9 步。

**前端蒙版编辑**（`canvas-node-mask-edit-dialog.tsx`）：2D canvas 画笔 paint/erase（`globalCompositeOperation` 切换）、笔刷粗细、stroke 历史 undo/redo，输出 `maskDataUrl`（叠加预览）+ `binaryMaskDataUrl`（二值蒙版，作为第二文件上传）。

依赖/许可：Goohaitools/GulfSeaTools=GPL（HTTP only）；Qwen-Image-Edit-2511 基模许可 `[UNKNOWN 需核]`；`turbo_int8_convrot` 社区转换权重许可 `[UNKNOWN]`；LoRA「一致性无偏移/万物移除」许可 `[UNKNOWN]`。

### 2.3 图片转 3D 环视取景（三条独立路 + 前端 viewing）

**A. Idol 单图→3D 高斯泼溅**（`workflows/image-idol-3d.json`）：
`LoadImage`→`BiRefNet`（ZhengPeng7/BiRefNet 抠背景）→`IdolPreprocessImage(mode=synthetic)`→`TripoSplatConditioning`（DINOv3 ViT-H + FLUX.2 VAE）→`Idol UNet(fp16)`→`KSampler(50 步,cfg4,euler)`→`VAEDecodeTripoSplat(num_gaussians=262144)`→`SplatToFile3D(ply)`→`SaveGaussianSplat`；旁路 `IdolInputCamera`+`RenderSplat` 出输入视角预览。
**原理：单图直接生成 26 万个 3D 高斯（TripoSplat 架构），不是深度图反投影。**
视频环视版（`video-image-idol-3d.json`）：泼溅→`SplatCameraOrbit`（yaw 360°、pitch -15→15、distance 2.8、fov 50、120 帧@24）→`RenderSplat`→`VHS_VideoCombine`。**相机轨道 = 绕物体一圈的 orbit 参数化渲染。**

**B. MoGe 深度→网格**（`workflows/image-moge-scene.json`）：
`DownloadAndLoadMoGeModel(ViT-L,fp16)`→`MoGeInference(resolution_level=6,batch=4,force_projection,refine_steps=3)`→输出 `depth_colored` + `MoGePointMapToMesh(decimation=2,discontinuity_threshold=0.04,texture=true)`→`RenderMesh` 预览 + `SaveGLB`。**原理：单目深度/点图→带纹理网格 GLB。**

**C. Scene3D 全景路**（`src/scene3d.js` 编排 + `tools/scene3d_pano.py`，Pillow/numpy/cv2）：
① 把源图摆到等距柱状画布 → ② `image-scene3d-pano.json`（H3-Image int8 + Qwen3-VL-32B int8，**5664×2832** 2:1 全景，4 步 cfg1 euler，SageAttention patch，工程化等距柱状 prompt）→ ③ 备接缝条带+蒙版 → ④ `image-scene3d-seam.json`（`GrowMaskWithBlur(expand56,blur20)`→`InpaintModelConditioning(noise_mask)`→Qwen2.1-turbo-int8 + `TaiYangH3ActivationChunk` + `TESpeedQwenImage21`(attention=kitchen_int8、step_cache=te_predictor、reuse_threshold=0.06、predictor_error_limit=0.08) + `QwenImage21Cache`，6 步，prompt「Remove the visible seam…」）→ ⑤ 拼回 → ⑥ **metrics 门禁**（5664×2832、边缘 MAE≤4、亮度差≤2、人脸数）。**这是唯一接了 TE-Speed 的工作流。**

**前端 viewing**（`infinite-canvas/web/src/components/canvas/`）：
- `model3d-node-content.tsx`：按 `metadata.model3dEngine` 分派 panorama/mesh/splat；splat 用 **three/webgpu + `GaussianSplatPLYLoader` + `GaussianSplat`**（three 0.186 原生高斯泼溅），boundingSphere 自动取景。
- `scene3d-node-content.tsx:590-716`：**反球面全景查看器**——`SphereGeometry(10,64,40)` + `geometry.scale(-1,1,1)`（内壁贴图），第一人称 yaw/pitch（rotation order YXZ）拖拽环视，滚轮 fov 35–90，**capture=渲染→2D canvas→PNG dataURL（即「环视取景」抓一张透视照片）**，WebGPURenderer + forceWebGL 回退，视角持久化到节点 metadata。
- `camera-orbit-widget.ts`：**不是 3D 查看器**，是提示词相机 rig（azimuth/elevation/distance→`<sks> front view…` 多视角 prompt，改编自 ComfyUI-qwenmultiangle），用于 angle 对话框。

### 2.5 生成视频加速（代码/JSON 里的具体接法）

1. **8 步草稿 = SelfLift 两段采样**（`h3-ref2va-drama*.json` 节点 78）：`BasicScheduler(simple,8)` + `SelfLiftH3Sampler(transition_step=6, lowres_scale=0.6, rho=0, w_min=0.3, w_max=1, upscaler_model=minimax_h3_latent_upscaler_3d_fp16, upscaler_unload=true, highres_tiling=false)`。**前 6 步在 0.6× 低清 latent 跑，第 6 步用 3D latent 上采样器升到全分辨率，后 2 步全分辨率精修**。SelfLift 授权链不完整→不随包。
2. **SageAttention**：`MiniMaxH3MemoryEfficientSageAttentionPatch`（KJNodes 封装，GPL；SageAttention 本体 Apache-2.0）挂在 UNet 后；`zimage-accel.js` 用 `PathchSageAttentionKJ`。
3. **INT8/FP8 量化**：H3 `Singularity_Pruned_v1.3_int8`、Qwen `turbo_int8_convrot`、Qwen3-VL-32B int8、RelayVSR int8_convrot（权重级）；`SolAttnPatch` int8_qk/int8_pv（注意力计算级）。
4. **VDN**（vdn 变体）：`ApplyVDNH3Advanced`（stage-dmd-step-250 蒸馏 checkpoint + turbo adapter + grouped 窗口注意力）。
