## 一、四层格局（先看这张）

| 层 | 是什么 | 和本项目的关系 |
|---|---|---|

## 二、第 1 层：开源画布 SDK / 引擎

| 项目 | 星数 | 渲染 | 定位与要点 |
|---|---|---|---|
| **tldraw** | 45.5k | DOM | 事实标准的「无限画布 SDK」。Signals 状态层 + Record Store（快照导入导出）+ `@tldraw/sync`（自托管多人协作，Cloudflare Durable Objects）+ AI starter kits。**注意：生产环境商用需付费许可（约 $6,000/年）**，非 OSI 认证开源 |
| **Excalidraw** | 120k | Canvas 2D | MIT，手绘风白板。**可嵌入任意 React 应用**，内置协作，无内置后端（需自配持久化） |
| **React Flow / Xyflow** | 30k+ | DOM | **节点图专用**（非通用白板）。本项目即基于此，v12 + `@xyflow/react` |
| **LiteGraph.js** | 8k+ | Canvas 2D | ComfyUI 前端的雏形，轻量节点图引擎 |
| **Konva / Fabric.js** | 12k / 29k | Canvas 2D | 底层 2D 图形库，给图元不给白板，做画布要自己搭全套 |
| **Penpot** | 30k+ | SVG/DOM | 开源设计+白板平台，可自托管，比 Excalidraw 重 |

**行业公认性能门槛**：10,000+ 对象需要 **WebGL 渲染器 + 空间索引**，纯 DOM 方案会退化。
（多篇 2026 评测共同口径；自建无限画布+CRDT 多人的复杂度评为 **9/10**，3–4 人团队需 6–9 个月。）

## 三、第 2 层：开源 AI 节点工作流

| 项目 | 要点 |
|---|---|
| **ComfyUI** | 可控性天花板。节点式 DAG、6 万+ 自定义节点、数千条共享工作流、App 模式（简化表单视图）。2026 年推出 **Partner Nodes**，把 30+ 商用模型（Veo / Nano Banana / Kling / Runway / Luma / Seedance / Topaz / ElevenLabs…）接进同一张图。**已从「竞品」变成「底座」**——SwarmUI、RunningHub 等都跑在它上面 |
| **InvokeAI** | SD 系开源平台。**Form Builder**：技术负责人搭复杂图，团队成员只填简化表单（参数锁定防呆）。Canvas Output 节点 + 图层式 inpaint |
| **SwarmUI** | ComfyUI 的简化 UI 壳，把 ComfyUI 当执行后端 |
| **Infinite-Canvas**（开源） | 普通画布 / 智能画布**双模式**（节点编辑 ↔ 卡片式免连线）；全局素材库；循环节点批量生成变体；多后端聚合（本地 ComfyUI / 云端 / 三方 API）。**本项目早期主路径，后自研替换** |
| RunningHub（国内云） | ComfyUI 云平台，预装数千节点，可发布 AI 应用 |

## 四、第 3 层：商用 AI 无限画布（通用创意）

| 产品 | 画布形态 | 差异化 |
|---|---|---|
| **Krea (Krea Nodes)** | 节点 + 自由空间布局 | **实时生成**（边画边渲染，<2s 延迟，LCM 1–4 步）；LoRA 微调；**无公开 API** |
| **Freepik Spaces** | 无限画布 + 节点 | 绑定 Freepik **2.47 亿**素材库；实时协作（≤10 人）；2026 初加视频生成 |
| **Flora** | 无限画布 | 面向**叙事/分镜**；Flows 把场景描述·角色参考·风格指南串成故事弧；支持导出 PSD 图层；插件接 PS/Figma |
| **Phygital+** | 节点画布 | 30+ 模型（含 **LoRA 训练**）；团队共享工作区 + **版本历史** + 角色权限 + 团队分析 |
| **Wireflow** | 节点画布 | **整张图可直接发布为 REST 端点 / Webhook / 定时任务**；批量生成。API-first |
| **Figma Weave**（原 Weavy） | 节点画布 | Figma 生态内，节点编辑与合成最强；**无公开 API** |
| **Higgsfield** | 画布 | 相机/运动控制一等公民；从 $9/月；偏短视频广告 |
| **Pixelz / Astorie(原 Martini)** | 无限画布 + 节点 | 60+ 模型堆到画布；视频优先 |

**共同信号**：模型聚合（15–60+）、模板/社区复用、实时协作、对外 API。
分水岭是 **「画布能不能被代码调用」**——只有 Wireflow 与 ComfyUI 做到了。

## 五、第 4 层：影视 / 短剧垂类节点画布 ★ 本项目赛道

### 5.1 第一梯队（最像，直接竞对）

#### 小云雀 AI（字节跳动 · 剪映系 · `xyq.jianying.com`）
> **与本项目功能重合度最高**，几乎是同一条产品线。

- **自由画布（无限画布）**：剧本节点 / 角色卡 / 场景资产 / 视频片段全部平铺在画布上
- **@ 素材调度**：节点内 `@` 直接调用画布内全部素材，**自动建立连线**
- **3D 导演台**：白模调站位、动作、机位、运镜；内置**时间轴**可摆关键帧、**直接录制运镜视频**接入画布当动态 Layout；可用 AI 识图上传概念图**自动生成 3D 场景**；预置人物/群众/动物/家具/植物素材与常用机位
- **自研模型**：`ScriptBird`（剧本：构思→大纲→剧本→改写）+ `AnyCook`（基于 Seedream 的人物/场景生图）
- **团队协作**：多人协同创作 + 跨端资产同步（Web/APP）
- **与剪映深度打通**：生成 → 精剪一站式
- **成绩**：全网累计播放 **60 亿+**，千万播放级作品 **30+** 部；3 年投 1 亿积分做创作者激励

#### LibTV（LiblibAI · `liblib.tv`）
- **无限画布 + 节点式工作流**：5 种节点 = 文本 / 图片 / 视频 / 音频 / **脚本**
- **脚本节点是灵魂**：给一段剧情 → 自动拆成带景别·运镜·动作描述的分镜脚本 → 一键批量生成分镜图 → 一键批量转视频 → 自动拼接
- **20+ 图像模型 / 30+ 视频模型**：Kling 3.0、Wan 2.6、Seedance 2.0、PixVerse、豆包、Kimi、智谱
- **角色一致性**：三视图 + **主体库**（角色五官/服饰全局锁定，跨分镜跨集复用）
- **多机位宫格分镜**（9/25 宫格）+ 3D 导演台 + 20 余项专业功能
- **Agent 双端**：CLI（`libtv login`）+ Skill 包（`npx skills add libtv-labs/libtv-skills`），一句话从剧本到成片
- **Skill 商店 100+**（2026-07 上线）：韦斯安德森 / 王家卫 / 是枝裕和 / 新海诚 / 皮克斯等美学风格
- **团队版**：多人实时协作共享画布 + 统一团队资产库
- 与 **300+ 短剧公司**合作，内置 100+ 标准化 Skill

#### TapNow（深圳添科智能）
- **Tapflow 无限节点画布**：脚本 / 分镜 / 生图 / 视频 / 音频 / 导出均为独立节点，**支持并行多版本生成与分支调试**；非破坏性编辑（改任一节点自动更新后续）
- **Agent OS**（2026-06 升级）：理解画布上每个节点及其连接关系，**主动预判下一步**
- **导演级控制**：JSON 级指令；推拉摇移跟升降；焦距/光圈/景深/快门角；关键帧动画、变速曲线、时间重映射、多机位多轨同步
- **一致性**：自研 **Nano Banana** 模型解决角色/商品跨镜头不一致
- **一键拉片**：上传参考片 → 自动解析镜头语言 / 色调 / 景别 → 可编辑分镜表
- **TapTV 开源社区**：全球首个 AI 视觉创作开源社区，**12 万+ 公开工作流**可一键克隆
- **15+ 模型**：Gemini 3、Sora 2 Pro、Veo 3.1、Kling、Runway、Luma、MJ、Flux、Wan、海螺、Pixverse、Grok、Nano Banana
- 数据：月访问量 72–84 万；中国 56% / 美国 14%；67% 直接访问；戛纳电影节技术合作方；与「影视飓风」联合课程销售额 700 万+

## 六、和拾光剪影的对照（谁最像）

| 能力 | 小云雀 | LibTV | TapNow | **拾光剪影** |
|---|---|---|---|---|
| 无限画布节点编排 | ✅ | ✅ | ✅ | ✅ |
| 脚本→分镜自动拆解 | ✅ | ✅ | ✅ | 部分（`breakdownStoryboard`） |
| 3D 导演台（白模调机位） | ✅ **+录制运镜视频** | ✅ | — | ✅（`dummy13-v3` 素模、群像模板） |
| 角色一致性（三视图/主体库） | ✅ | ✅ **主体库** | ✅ Nano Banana | ✅（20 字段 schema，**无漂移锚点权重**） |
| @ 素材调度 | ✅ **自动连线** | — | — | ✅（`expandCharacterMentions`） |
| Agent 双端（CLI/Skill） | ✅ | ✅ **100+ Skill** | ✅ Agent OS | ⚠️ 有 Agent 但**无对外 Skill/CLI** |
| 工作流模板/社区复用 | ✅ | ✅ | ✅ **TapTV 12万+** | ⚠️ 有 `projectZip` 无社区 |
| 多人协作 | ✅ | ✅ 团队版 | ✅ | ❌ |
| 与剪辑器闭环 | ✅ 剪映 | 内置合成 | 内置导出 | ✅ `sendBlobToEditor` **本机剪辑器** |
| 本地部署 / 离线 | ❌ | 部分（私有化） | ❌ | ✅ **桌面端，本机 GPU + NVENC** |

**结论**：
1. **赛道判断正确**——「无限画布 + 3D 导演台 + 角色一致性 + Agent」正是 2026 年影视 AI 的标准答案，
   小云雀/LibTV/TapNow 三家都在解同一道题。
2. **重复度最高的对手是小云雀**——字节/剪映系，且已跑出 60 亿播放的成绩单，资源量级不同。
3. **本项目唯一结构性差异**：**本地优先的桌面剪辑闭环**（本机 GPU、NVENC、素材不出机、时间线真相源）。
   云端三家的短板恰好是「重生成、轻精剪」，而我们**有真剪辑器**。
4. **最该补的三样**（对照本表 ⚠️/❌）：**对外 Agent 接口（Skill/CLI）** · **工作流模板社区** · **多人协作**。

## 七、一句话速记

> **开源**：地基看 tldraw / Excalidraw / React Flow；管线看 ComfyUI / InvokeAI。
