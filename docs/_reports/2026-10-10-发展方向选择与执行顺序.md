# 发展方向选择与执行顺序（2026-10-10 收口定稿）

> **你的问题**：站在产品和项目工程师角度，后续改进发展该怎么选、怎么办？
> **本文性质**：不是新任务清单（那是《补强任务总清单》的事），是**选择的尺子和主干道**——
> 以后每次犹豫「先做什么」时，回来看这一页。

---

## 0. 一把尺子（所有选择的判定标准）

项目现在的处境：**北极星主张已锋利**（第一条打通剪辑↔AI 画布生成往返路径的产品）、
**工程底座已一流**、**但全链没串跑过一集、没有真实用户**。

所以一切改进项只用这四个问题过滤，按顺序：

1. **它是否让「3 分钟全链 demo」更早可演示？**（最高优先）
2. **它是否补强 round-trip 主张**（让「往返」这条差异化路径更深、更顺、更可见）？
3. **它是否在拆除演示时会当众翻车的隐患**（工程债、假数据、账本零流量）？
4. **以上都不是 → 降级或砍掉**（无论技术上多有趣）。

> 小白翻译：现在公司只有一个目标——**做出一场 30 秒就能看懂的演出**（demo）。
> 能上台演的优先，让演出更好看的其次，防止台上忘词的再次，跟演出无关的全部让路。

## 1. 主干道（三段式，每段有明确的「过关」信号）

### 第一段 · 修地基（现在 → 2026 年底）：让闭环「真实工作」

| 刀 | 干什么 | 为什么排第一 |
|---|---|---|
| P0a 首流量验收 | 真抽一卡，亲验账本落笔 | 账本现在是空的 `{}`——**演示抽卡可复现时翻车就是在这里**（尺子问题 3） |
| P0b 本地生图入闭环 | 本地路径进账本+seed 回显 | 同上；零成本主力必须在闭环内 |
| H1 三档路由 | 显存探测→自动选路 | 复合型产品的装机体验：核显用户装了也能用 |
| S1 编剧结构层 | 梗概→场次大纲 | demo 的内容源头起点（纯规则零 API 成本） |
| M1 定妆照 | 角色有照片 | demo 里角色一致性最直观的视觉证据 |
| H2 启动/工程项 T1/T2 | 量化档起步+temp 迁出+CI | 工程债顺手清 |

**过关信号**：账本有真实流量、推荐回传生效、同一 prompt 重抽能复现；三档路由 reasons 可见。

### 第二段 · 串全链（2027 Q1）：做出 demo 本体

S2 LLM 编剧 → S3 剧本→分镜贯通 → R1 一键粗剪 → 入轨精剪 → 成片。
用「梦浮生」语料做一集 3 分钟。**这一段结束时，项目从「能力的集合」变成「一场演出」。**

**过关信号**：从一句话梗概到成片，全程人工只过 3 个卡点；导出的成片能放给人看。

### 第三段 · 拿真实反馈（2027 Q2 起）：让市场投票

demo 完成后**必须停新功能两周**，做两件事：
1. 找 **3-5 个真实短剧/AIGC 创作者**用一次（他们被「剪辑工具+生成工具来回导出」折磨过，
   无需品类教育）——记下他们在哪一步困惑、哪一步说「哇」；
2. 把 demo 同步整理成**求职作品集形态**（2027-04 投递窗口，这是你个人的硬节点）。

**过关信号**：至少 1 个创作者在没有你指导的情况下独立跑完一集，并说出「这个往返真的省事」
——这句话出现之前，「品类成立」都只是假设；出现之后，才谈加大投入（G 系列体检报告、
D 轨装机、甚至小众商用）；反之，用户反馈指向哪里就改哪里——**他们的困惑比我的一切分析值钱**。

## 2. 三个「怎么办」的明确答案（工程师视角）

**功能面**：只走主干道三段。任务清单里 G2/G3/R2/M2/M3/D 轨全部排在第二、三段之后，
不提前——不是不重要，是**顺序即战略**。

**工程面**：纪律一条不减（11 门禁/棘轮/冻结区），这是演示日当众写代码、打开仓库都敢让人
看的底气；但**不再新增门禁类型**（边际收益已低），精力转向覆盖率上行和 `app/temp` 清债。

**路线面**（易反复的三个点，一次性钉死）：
- 算力 = 三档自适应（已定稿，H1/H2 落地即可，不再讨论）；
- ComfyUI = 只内化其优化能力，永不要求用户下载（已定稿）；
- 对外一句话 = **「第一条打通剪辑与 AI 生成往返路径的产品」**——所有文档/演示/面试
  都用这句开场，别再用「AI 短剧剪辑系统」（后者会被听成又一个剪映）。

## 3. 一页收束

| 时间 | 干什么 | 产出 |
|---|---|---|
| 现在-年底 | 修地基（P0/H1/S1/M1） | 闭环真实工作 + 三档路由 |
| 2027 Q1 | 串全链（S2/S3/R1） | **3 分钟全链 demo** |
| 2027 Q2 | 拿反馈（停新功能两周） | 3-5 个真实用户验证 + 作品集 |
| 之后 | 由反馈决定 | 加大投入 / 转向 / 收口求职 |

> **给小白的一句话**：别再问「还有什么该做」——该做的都在清单上了；
> 以后每次犹豫，就问「这件事能不能让那场 30 秒的演出更早、更稳、更好看」。
> 能，就做；不能，就放到演出之后。
