# TRAE 好应用大赏赛参赛打包设计

日期：2026-11-18

## 1. 当前目标

先交付一个可供大赛评委安装、启动和体验的 Windows 应用程序安装包。评委应能看到拾光剪影的主界面、画布、剪辑和数字人等已实现页面，并能使用不依赖本地模型权重的基础功能。

本轮只处理应用程序打包、安装、启动、卸载保护和交付说明，不开展社区模型接入或模型能力改造。

## 2. 已确认约束

- 交付形式：应用程序安装包，后续再制作演示视频。
- 首选路线：验证 Inno Setup 能否承载完整程序与 AI 运行时，避免因 NSIS 地址空间限制删减功能。
- 模型权重不随主安装包分发；离线模型部署与社区模型能力评估后置。
- 不修改现有产品架构、时间线真相源、画布真源和渲染调度。
- 不为了缩小体积随意删除运行库、插件、技能或数字人相关功能。
- 安装包不得携带本机日志、测试作品、私人配置、账号信息或密钥。

## 3. 当前事实基线

- 当前可用交付形态是绿色版；现有 NSIS 安装链路受体积限制，依据为 `docs/安装与部署.md` 第 2.7 节。
- 2026-11-12 实测完整产物约 6.35 GB，其中 `_internal` 约 1.96 GB、`runtime` 约 4.37 GB；真机启动正常，依据为 `.workbuddy/memory/topics/packaging.md` 第七节。
- NSIS 3.13 在本机 1.8 GB 测试成功，1.96 GB 与 6.35 GB 均因 32 位 makensis 地址空间限制失败；不是压缩率问题。
- 现有打包已具备插件、技能、运行时和卸载用户数据保护等契约，不应另造一套平行应用或裁剪版产品。
- Inno Setup 对本项目完整体积的支持尚未实测，属于待验证事项，不预先宣称可行。

## 4. 打包方案

### 4.1 首选：Inno Setup 完整安装包

1. 检查本机 Inno Setup 编译器与现有完整 `dist` 产物是否可用；缺失时明确安装或重建前提。
2. 复用现有版本号、应用元数据、用户数据保护和发布自检结果，新增内容只承担安装器构建，不修改应用业务逻辑。
3. 安装器应包含完整程序与运行时，排除 `.git`、日志、缓存、测试输出、用户作品和私人配置。
4. 保留安装目录选择、开始菜单入口、卸载入口和卸载时的数据保护提示。
5. 构建后核对产物版本、体积、文件清单和安装器日志，不以“生成了 exe”替代安装验收。

### 4.2 回退：NSIS 主程序＋独立运行时包

仅在 Inno Setup 实测不可行时启用：

- 主程序沿用现有 NSIS 安装体系，只处理已有文档明确识别的确定性冗余，并重新执行完整打包自检。
- AI 运行时作为独立扩展包交付，提供固定安装位置、校验清单和安装说明。
- 不把该回退描述为单一全集成安装包；提交材料中如实说明两个组成部分。

## 5. 验收设计

### 5.1 构建验收

- 安装器编译成功，版本号与 `app/version.py` 一致。
- 文件清单覆盖应用运行所需内容，不含本机产物与敏感信息。
- 现有打包契约测试、稳定性门禁和冻结区检查不因本轮改动出现新增失败。

### 5.2 安装与启动验收

- 在独立测试目录完成真实安装，不只解压绿色版代替安装测试。
- 从开始菜单或安装目录启动应用，主界面能够打开。
- 检查画布、剪辑和数字人等相关页面；仅验证已实现且不依赖未随包模型的行为。
- 检查后台日志，无启动致命错误、缺失模块或静默功能清空。

### 5.3 卸载与数据保护验收

- 卸载入口可用。
- 用户选择保留数据时，测试作品和配置不得被删除。
- 测试只使用专门创建的临时数据，不触碰真实用户项目。

### 5.4 交付验收

最终形成：安装包、版本与校验信息、简明安装说明、已知限制说明和实测记录。已知限制必须明确写出“模型权重未随包分发”，不得让评委误以为安装后即可离线生成。

## 6. 后续模型专项边界

打包完成后再单独评估用户提到的“索拉”等社区模型：

- 模型真实名称、来源、部署方式、输入输出协议和许可。
- 是否能通过现有 Provider、MCP、HTTP/API 或本地推理层接入。
- 是否能保持模型原本的文生图、图生图、文生视频、图生视频或其他能力，而不是只接入一个名称或聊天外壳。
- 失败、降级、素材出域、硬件要求和可复现验收。

上述内容不属于本轮安装包实施范围。

## 7. 完成判据

本轮完成不等于仅生成安装器文件。必须同时满足：安装器构建成功、独立目录安装成功、应用真实启动、核心页面可见、卸载数据保护通过、交付说明与已知限制齐全。若 Inno Setup 无法承载完整产物，则记录真实错误并转入既定回退路线，不隐瞒失败或删减功能冒充完整安装包。
