---

## 0. 一句话结论

**体积/算力最大**的是 **YuE2-3B 音乐模型**（24GB VRAM，本机 8GB 根本跑不动，已是"诚实失败+远程"）；
**成本与"素材出域"最大**的是 **云端视频 API**（dashscope/seedance/cogvideo，按量计费且素材出网）。
真正"用本地替换外网"的最大机会是 **gTTS/edge-tts → CosyVoice2/IndexTTS-2**（T2 正在做）。

## 2. 哪个最大、最该动

| 维度 | 最大者 | 我的判断 |
|---|---|---|
| **体积/算力** | YuE2-3B（24GB） | 已是"诚实失败+远程"，不算硬伤；但若想本地全曲生成，需换小模型 |
| **成本/出域** | 云端视频 API | **最该重视**：短剧出片是高频动作，按量计费 + 素材出网 |
| **可替换性最高** | gTTS/edge-tts → 本地 TTS | 收益最直接（既省外网依赖，又解锁多角色音色） |

## 3. 保留 / 替换建议（供思考）

| 依赖 | 建议 | 理由 |
|---|---|---|
| YuE2-3B | **保留远程，加本地小模型兜底**（如 Stable Audio Open / MusicGen-small，6–8GB 可跑） | 短剧 BGM 未必需要全曲生成；本地小模型够用就够 |
| 云端视频 API | **保留，但强化 `SHIGUANG_NO_EGRESS` 策略**（敏感素材本地、普通素材云端） | 完全去云端在 8GB 上不现实（本地视频生成吃力）；用开关把"是否出网"变成显式决策 |
| gTTS / edge-tts | **替换**为 CosyVoice2/IndexTTS-2（本地克隆） | 既去外网依赖，又解锁 T2 多角色音色 |
| whisper / RealESRGAN / Depth | **保留** | 本地可跑、无出域问题、体积小 |
| Coqui Tacotron2 | 保留作 CPU 兜底 | 无外网、固定音色可用 |

---

## 4. 一个诚实的提醒

「素材不出域」不是"零云端"，而是**把出网变成显式决策 + 可控开关**：
- 已有点：`SHIGUANG_NO_EGRESS=1` 硬开关（无条件返回 local）；
- 缺的是：**界面上的"本次出网"提示**（哪些 provider 会把素材发云端、预估费用）—— 这比单纯加模型更值得做。

### 5.3 YuE2 压缩方案 + license 陷阱（关键）

**① 能压到 8GB（技术上可行）**：`audio.cpp` / `yue2.cpp` 已出 GGUF 量化，实测：

| 精度 | 权重体积 | 峰值显存 | 说明 |
|---|---|---|---|
| BF16（原始） | 7.2GB | 12.5GB | 官方，需大卡 |
| **Q8_0** | 3.8GB | **8.7GB** | 16GB 卡稳；RTF 0.20 |
| **Q4_0** | 2.7GB | **7.6GB** | 8GB 卡勉强（RTX 2070 8GB 实测跑通全曲 ~5 分钟） |

Windows 已支持（audio.cpp v0.8.0 / Pinokio GROOVE 1.0.2）。⚠️ Q4 有轻微质量损失（诚实说明）。

**② 但 license 是硬伤**：YuE2-3B 权重 = **CC BY-NC 4.0（非商用）**，GGUF 量化版同样 CC BY-NC。
商用需单独授权。**这比显存更关键**——若做商用短剧，YuE2 权重不能用。

**③ 商用替代（权重 Apache/MIT，可商用）**：

| 模型 | 权重许可 | 显存 | 状态 |
|---|---|---|---|
| **ACE-Step 1.5** | Apache/MIT | 8GB 以下 | ✅ 还在更新，首选 |
| DiffRhythm | Apache-2.0 | 8GB（--chunked） | 停更 10 个月 |
| YuE-v1 | Apache-2.0 | 较高 | 老版 |

### 5.4 对「缺统一供应商」的回答

用户痛点：模型种类多、显存环境要求各异、自己全本地部署不现实、缺统一入口。

**结论：你其实已经有统一网关（`ai_engine.py`）**——16 云端 provider + Ollama 本地，统一路由 + 降级链。
缺的不是"新做一个供应商"，而是**把音乐/对口型/视频也接进这个统一路由**（现在音乐走 YuE 专用路径、对口型是刚写的骨架，都还没接进 ai_engine 的 provider 抽象）。

**分层部署策略（建议）**：

| 层 | 模型 | 理由 |
|---|---|---|
| 本地（轻量高频、隐私敏感） | whisper / Depth / RealESRGAN / ESPCN / 嘴型动画 | 零成本、无出域 |
| 本地（中频、隐私敏感） | funasr / CosyVoice2 / MuseTalk | 配音对口型涉及角色音色，不宜出网 |
| 云端（重量级、低频） | 视频生成 / 音乐生成 | 按量计费更划算 |
| 云端 GPU 托管 | YuE2 商用替代 或 24GB 大模型 | SiliconFlow / 火山方舟 / 阿里百炼 / Replicate 已托管大量开源模型 |
