# 拾岚表情帧规格（美术交付单 v1.0）

> **用途**：给 5 张待生成表情帧的**唯一交付规格**。图一到位，代码零改动自动点亮
> （只改 `mascotFrames.ts` 的 `ready: true`，并过守卫）。
> **配套**：角色圣经 [`拾岚形象规范.md`](拾岚形象规范.md) §4；技术文档 §14。
> **建档**：2026-10-20 · 现状：**3 帧就绪（neutral/blink/cheer）+ 5 帧待生成**。

---

## 1. 硬规格（不合规直接退回，不靠人眼）

| 项 | 规格 | 判据 |
|---|---|---|
| 画布 | **316×480**（与现有三帧完全一致） | `_verify/check_mascot_assets.py` |
| 背景 | 透明（alpha），无底色、无投影 | 同左（alpha 质心） |
| 质心对齐 | alpha 质心与 `pet_neutral` 偏差 **≤ 2px** | 同左（实测现有三帧 ≤0.2px） |
| 角色一致性 | 同一角色、同一套橙白毛衣/白裙/白袜、同一耳朵与尾巴比例、正面站立 | 人眼 + 与 neutral 并排 |
| 构图 | 全身，脚底位置与 neutral 一致（不得上下漂移） | 质心 + 并排叠图 |
| 命名 | `pet_<id>.png`，放 `vendor/shiguang-canvas/public/mascot/` | 守卫双向校验 |

> **为什么质心要卡 2px**：表情帧是**叠层**渲染（同一 `<img>` 位置切换不透明度）。
> 质心一偏，换表情时整个人会「跳一下」——这是本项目已经踩过的位移类问题。

## 2. 五帧设计要点与状态映射

| id | 文件名 | 接哪个状态 | 表情设计 |

|---|---|---|---|
| `thinking` | `pet_thinking.png` | `thinking`（画布有任务在生成） | 眉微皱、视线偏上（思考）；嘴保持自然闭合；耳朵略前倾 |
| `sleepy` | `pet_sleepy.png` | `sleepy`（idle 静置 75s） | 眼半闭（上眼睑压下 ~50%）、嘴角放松；头略低 2°；**不画 💤**（气泡由 UI 负责） |
| `sad` | `pet_sad.png` | `error`（任务失败） | 眉尾下垂、耳朵**垂下来**（与 neutral 的竖耳明显不同）、嘴角向下；不哭、不夸张 |
| `surprised` | `pet_surprised.png` | `awaiting`（等你确认） | 眼睛睁大、瞳孔略放大、嘴微张；耳朵竖起；**不画感叹号**（气泡负责） |
| `proud` | `pet_proud.png` | **不接状态机**（品牌/表情包专用） | 小幅得意：下巴微抬、眼睛弯一点、尾巴翘起；不夸张 |

> `proud` 只用于宣传与表情包——**不为接而接**。要接状态时先在角色圣经改映射，再改 `pickFrame()`。

## 3. 生图提示词（可直接投喂文生图/图生图模型）

**一致性策略（关键）**：以 `pet_neutral.png` 作为**参考图**（图生图 / IP-Adapter / reference image），
提示词只描述**表情变化**，不重新描述角色，避免换脸换衣服。

### 3.1 通用前缀（每条都带）

> 中文：Q 版 2 头身拟人狐狸少女，橘白双色毛发，橙色毛衣 + 白色百褶裙 + 白袜白鞋，大尾巴，正面全身站立，可爱日系插画，干净描边，透明背景。
> English: chibi 2-head-tall anthropomorphic fox girl, orange-and-cream fur, orange knit sweater, white pleated skirt, white socks and shoes, big fluffy tail, front-facing full body, cute Japanese anime illustration, clean outline, transparent background.

### 3.2 逐帧差异

| id | 中文追加 | English append |
|---|---|---|
| `thinking` | 微微皱眉，眼睛看向斜上方，嘴巴自然闭合，耳朵略向前倾 | slightly frowning, eyes glancing up, mouth closed, ears tilted slightly forward |
| `sleepy` | 眼睛半闭（上眼睑压下约一半），表情放松，头略低 | eyes half closed (upper lids half down), relaxed face, head slightly lowered |
| `sad` | 眉毛下垂，耳朵垂下来，嘴角向下，眼神委屈但不哭 | eyebrows drooping, ears drooping down, mouth corners down, aggrieved look without tears |
| `surprised` | 眼睛睁大，瞳孔放大，嘴巴微张，耳朵竖起 | wide open eyes, enlarged pupils, mouth slightly open, ears perked up |
| `proud` | 下巴微微抬起，眼睛弯成自信的弧线，尾巴翘起 | chin slightly raised, confident curved eyes, tail lifted |

### 3.3 负向提示（防跑偏）

> 不要换衣服/换发色/换物种；不要侧身或背面；不要缩放角色；不要加背景、文字、气泡、💤、感叹号、阴影；
> 不要 3D 写实、不要厚涂、不要美式卡通。
> no outfit change, no hair color change, no species change, no side/back view, no scaling,
> no background, no text, no bubbles, no emoji, no drop shadow, no 3D realism, no thick paint.

## 4. 验收清单（交付方自检 + 维护方复跑）

- [ ] 文件名正确、放在 `public/mascot/`
- [ ] 316×480、透明底
- [ ] 与 neutral 并排叠图：**身体轮廓不位移**（质心 ≤2px，守卫自动判定）
- [ ] 服装/配色/耳朵/尾巴与 neutral 一致
- [ ] 没有背景、文字、气泡、emoji、投影
- [ ] `mascotFrames.ts` 对应 `ready: true`
- [ ] `python _verify/check_mascot_assets.py` 输出 OK
- [ ] `pnpm --filter @shiguang/libtv test` 全绿

---

## 5. 入库流程（三步，缺一不可）

1. **放图**：`pet_<id>.png` → `vendor/shiguang-canvas/public/mascot/`
2. **登记**：`vendor/packages/libtv/src/mascot/mascotFrames.ts` 对应行 `ready: false → true`
3. **验证**：`python _verify/check_mascot_assets.py` + 前端测试

> 守卫会同时抓两种错：**声明 ready 但没图**（运行时 404）与**有图但没登记**（死资源）。

---

## 6. 代码会自动做什么（不需要改组件）

- `pickFrame(status, sleepy)` 选首选帧 → `resolvedFrame()` 收敛到真实存在的帧；
- 缺图时**回落 neutral**，并在 `data-frame` 如实标出实际渲染帧（不假装有表情）；
- 新帧就绪后自动挂进叠层，按 `[data-frame="<id>"]` 切不透明度；
- 眨眼只在睁眼类帧播放（`cheer` / `sleepy` 不眨）。
