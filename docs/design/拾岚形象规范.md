> **定位**：拾岚是「拾光剪影」唯一代表形象。本文是形象的**单一事实源**——
> 画布桌宠、关于页、启动页、文档插图、宣传物料一律以此为准；与本文冲突的旧描述一律作废。
> **建档**：2026-10-20 · 依据：`assets/mascot/` 母版 + `@shiguang/libtv/src/mascot/` 现有实现（读码核对，非想象）。

> **与「虚拟形象体系」的边界（避免双事实源）**
> - 本文管的是**品牌代表形象**（拾岚）：品牌位、只做展示与桌宠交互，**不可捏脸、不进角色库**；
> - 角色库 / 捏脸 FaceCard / 3D 人偶 / 数字人 / 口型是**内容生产的「演员」系统**，
>   见 [`docs/虚拟形象体系全景.md`](../虚拟形象体系全景.md)（专题综述，非单一事实源）；
> - 两者不混：给拾岚换装 = 品牌资产（`assets/mascot/` 8 套涂装）；给角色库角色捏脸 = 生产工具。

## 4. 表情与状态（桌宠状态机）

| 状态 | 触发（真实数据） | 表情帧 | 动效 | 气泡 | 光晕 |
|---|---|---|---|---|---|
| `idle` | 无任务 | neutral | 呼吸 3.6s + 浮动 2.9s + 眨眼 2.2~5.5s + **待机小动作** | — | `#F7A061` |
| `thinking` | 节点 data.status ∈ generating/loading/pending/queued/running/analyzing | neutral | 呼吸加速 1.7s | 正在生成… | `#7EA6FF` |
| `awaiting` | 确认弹窗 `.sg-modal-root` 存在 | neutral | 周期小跳 1.9s | 这步要我继续吗？ | `#F97316` |

| `error` | 节点 failed/error | neutral | 一次性摇头 0.5s | 出错了 | `#D98282` |

## 5. 动效规范（数值即事实，改数值先改本文）

| 动效 | 参数 | 说明 |
|---|---|---|
| 呼吸 | 纵向压扁 **1.4%**，周期 3.6s | **绝不高于原高**（变高会被读成弹跳，抢掉真弹跳的信号） |
| 浮动 | ±5px，周期 2.9s | 与呼吸分层叠加，互不覆盖 |
| 眨眼 | 间隔 2.2~5.5s 随机，单次 180ms | 18% 二连眨、12% wink（`planBlink`） |
| 待机小动作 | 间隔 4~9s 随机；歪头 45% / 轻摇 35% / 抖耳 20% | 歪头 ±2.2°、轻摇 ±1.2°、抖耳 scale 1.02 |
| 睡眠 | 静置 75s；呼吸 5.2s；下沉 3px | 唤醒：指针进入 / 点击 / 状态变忙 |
| 好奇 | 半径 160px；最大倾角 2°；过渡 0.28s | 指针离开半径即归位 |
| 状态反应 | hop 0.62s / shake 0.5s | 两端必须回中立位（回归用例锁死） |

**三条硬约束**：
1. 只动 `transform`/`opacity`（合成器友好），不动 width/height/top/left
2. 尊重 `prefers-reduced-motion`：开启时只保留呼吸与状态变化
3. 状态必须来自真实数据（`petActivity`），**禁止随机表演成功/失败**
