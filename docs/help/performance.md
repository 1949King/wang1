# 📊 性能监控

实时监控系统资源使用情况。

---

## 监控指标

| 指标 | 说明 |
|------|------|
| CPU使用率 | 处理器占用百分比 |
| 内存使用 | RAM 占用及总量 |
| GPU使用率 | 显卡占用（需NVIDIA显卡） |
| GPU显存 | 显存使用量/总量 |
| 磁盘使用 | 工作目录磁盘占用 |

---

## GPU 监控要求

需要 NVIDIA 显卡 + nvidia-smi 驱动。如果没有独立显卡，GPU 区域将显示为「N/A」。

---

## 渲染性能

在渲染导出时会显示：
- 当前帧率 (fps)
- 已处理帧数 / 总帧数
- 预计剩余时间
- 编码耗时

---

## 性能告警

当以下情况发生时，会自动提示：
- CPU 持续 > 90%
- 内存可用 < 1GB
- GPU 显存 > 95%
- 磁盘可用 < 5GB

---

## 实时日志

底部日志面板实时显示性能事件，包括：
- 任务开始/完成时间
- 资源峰值记录
- 异常事件告警
