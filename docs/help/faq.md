# ❓ 常见问题 (FAQ)

---

## Q1: 为什么AI没有反应？
A: 检查「模型广场」中是否已激活模型（圆形按钮为蓝色即为激活状态）。如果已激活仍无反应，请检查API Key是否有效，网络是否通畅。

## Q2: 支持哪些视频格式？
A: 支持 MP4、AVI、MOV、MKV、WebM 等主流格式。**剪辑与导出**推荐 MP4 (H.264)，兼容性最好；
但**画布内预览**只有 WebM (VP8/VP9) 能播 —— 原因见 Q16。

## Q3: 导出的视频有水印吗？
A: 本软件导出的视频**无水印**，完全归你所有。

## Q4: 本地运行的 AI 模型需要什么配置？
A: 推荐 NVIDIA 显卡 6GB+ 显存（如 GTX 1060 以上），16GB+ 内存。轻量模型（DeepSeek/Ollama 1.5B）也可以在 8GB 内存 CPU 上运行。

## Q5: 如何更新软件？
A: 当前版本通过手动下载更新。后续版本将支持自动更新检测。

## Q6: 我的数据安全吗？
A: 所有素材和项目文件均保存在本地。使用云端API时仅发送必要的提示词文本，不会上传视频文件。

## Q7: 文案生成为什么有时不准确？
A: AI生成结果受模型能力和提示词影响。建议：
- 使用 DeepSeek V3 或更高版本
- 在「文案生成」模块中点击「刷新」重新生成
- 手动微调生成的文案

## Q8: 批量处理任务会不会卡死？
A: 批量任务在后台线程执行，不会阻塞UI。可在「多任务管理」中查看进度、暂停或取消单个任务。

## Q9: 素材库支持哪些来源？
A: 素材库只支持本机文件导入（导入按钮 / 按类型浏览文件夹 / 拖拽到时间线）。免费或商用素材网站请到「帮助 → 素材网站直达」打开官网下载后，再回到素材库导入。软件不再内置在线素材目录。

## Q10: 如何选择合适的AI模型？
A:
- **免费/隐私优先**：使用 Ollama 本地部署（推荐 qwen2.5:7b 或 llama3.1:8b）
- **性价比最高**：DeepSeek（deepseek-chat，每百万token仅 ¥1）
- **最高质量**：OpenAI GPT-4o 或 Claude 3.5 Sonnet
- **国内首选**：豆包 doubao-pro-32k 或 智谱 GLM-4-Plus
- 可在「模型广场 → 性能对比」查看各模型详细对比数据

## Q11: 导出视频为什么很慢？
A: 导出速度取决于视频时长、分辨率、编码格式和硬件配置。优化建议：
- 降低导出分辨率（4K→1080p）
- 使用硬件加速编码（H.264 NVENC / Intel QuickSync）
- 关闭其他占用GPU的应用程序
- 批量导出时限制同时导出数（建议不超过3个）
- 可在「性能监控」页面查看实时CPU/GPU负载

## Q12: 如何备份我的项目和设置？
A: 两种方式：
- **项目文件**：所有 .aep 项目文件保存在 data/ 目录，直接复制备份
- **应用设置**：在「设置 → 导出设置」中将所有配置导出为 JSON 文件
- 恢复时使用「设置 → 导入设置」选择备份文件

## Q13: 插件安装后不生效怎么办？
A:
- 确认插件已在「插件中心 → 已安装」中显示并启用（开关为蓝色）
- 部分插件需要重启应用后生效
- 检查插件兼容版本是否匹配当前软件版本
- 在插件详情页点击「卸载」后重新「安装」
- 仍有问题可导入本地 .py 插件文件

## Q14: 多平台剧集筛选支持哪些平台？
A: 当前主要支持抖音平台。快手、视频号、小红书、B站等平台的数据接入正在开发中。可先使用「手动导入」方式添加其他平台素材。

## Q15: 性能监控中的数据准确吗？
A: CPU/内存数据通过系统接口获取，较为准确。GPU数据依赖 nvidia-smi（NVIDIA显卡）或 rocm-smi（AMD显卡）命令行工具，如未安装则显示 N/A。渲染统计数据来自内置渲染引擎的实际记录。历史趋势数据每2秒采样一次，可在「性能监控」页面查看。

## Q16: 为什么画布里的视频节点显示不出画面（黑框）？
A: 不是文件坏了，是**画布用的内置浏览器内核（Qt WebEngine，基于 Chromium 的免费构建）没有带 H.264/AAC 解码器** ——
而软件自己渲染出来的成片正是 H.264。所以 mp4 在画布节点里点开是黑的，WebM 正常。
现在节点会自动退回显示**首帧图**并写明这一点；要看片请：
① 双击节点右下的首帧缩略图，或 ② 在剪辑器里预览（走系统播放器，能正常播 H.264），
③ 团队面板里的附件可以点「下载」用系统播放器看。
（2026-11-02 实测：`canPlayType('video/mp4; codecs="avc1.42E01E"')` 返回空串、`<video>` 报 `error.code=4`、同文件的 WebM 正常。）

## Q17: 同事加入团队时不想念 IP，怎么做？
A: 用**配对码**（2026-11-02 新增，思路参考手机「多屏协同」；11-03 起可一次请多人）。
主机在「① 我当服务器」点「启动团队服务」→ 选「请 1/3/5/9 人」→ 点「让同事加入」，面板出 6 位数字；
同事在「② 我连别人的团队」最上面那栏输入这 6 位（**或者把整条邀请链接粘进去**）→
点「用码或链接加入」，地址自动找，不用问 IP。
四条要点：**2 分钟有效 / 能请几个人由你选 / 名额用掉一个变一个 / 不必当秘密**。
卡片上还有三个按钮：**复制码**（微信发比念更准）、**复制邀请链接**、**立即作废**（念给错的人时一键废掉）。
有人用码加入时面板会立刻绿字提示「李四 已用配对码加入」，不用手动刷新。
**配对只有这两条路**（二维码已于 2026-11-04 移除，它编的就是那条链接）。
扫不到/找不到时优先怀疑公司网络禁止 UDP 广播 —— 那种情况下改用**邀请链接**就够，链接里带着地址。

## Q18: 客户/甲方只想看不想让他改，怎么给？

A: 发码时把角色选成 **「只看（评审/甲方）」**（① 段出码那行第二个下拉）。
他进来能看全部项目、能提批注，但上传/拉取/改画布这些动作会被拒绝并说明原因。
另外**没拿码直接加入的人**（扫描局域网、手填地址）也默认是「只看」——
那条路本来只适合「同一间屋里临时连一下」。

主人可以在成员列表里随时升/降别人（「给编辑权」/「收回编辑权」）。收回比踢掉好：
他提过的批注归属不会丢。

## Q19: 怎么让同事对某一个镜头提意见，而不是发微信截图？

A: 画布上**点一下那个节点** → 面板 ⑥ 段写一句 → 点「提给「镜 03」」。
意见挂在节点上（不是挂在整份文档上），别人点「定位」画布就选中那一处。
不选节点也能提，那种挂在「整份画布」上（适合「整体色调偏冷」这类）。

提意见**不产生新版本** —— 否则每提一条就多一个 rev，「谁改了什么」会被意见淹掉。
处理完点「标为已解决」，默认只显示待处理的。
