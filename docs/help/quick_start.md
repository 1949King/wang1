# 🚀 快速入门

欢迎使用**拾光剪影** AI短剧编辑器！本指南帮你3分钟上手。

---

## 🎯 准备工作

1. 注册一个AI模型平台账号（推荐 DeepSeek 或豆包，免费额度友好）
2. 在对应平台获取 API Key
3. 在本软件中配置并激活模型
4. 准备一段测试视频

---

## 📹 三步上手指南

### 第一步：激活AI模型
打开「**模型广场**」→ 选择「DeepSeek」或「豆包」→ 填入API Key → 点击圆形按钮激活

### 第二步：导入视频
打开「**剪辑**」→ 点击「📁导入」选视频 → 视频出现在时间轴上 → 按▶播放预览

### 第三步：导出成品
调整好之后 → 点底部「💾开始导出」→ 选择MP4/1080p → 完成！
