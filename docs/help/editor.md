# 剪辑功能

视频编辑器是拾光剪影的核心功能。

---

## 时间线操作

### 基本操作
- **拖拽片段**：在时间线上选中片段后可拖拽调整位置（可吸附播放头与相邻片缘）
- **裁剪片段**：拖动片段两端边缘即可裁剪（松手写入 in/out，可撤销）
- **分割片段**：将播放头移到目标位置，按 `S` 键或工具栏分割
- **删除片段**：选中后 Delete；默认波纹删除（后片前移闭合空隙）
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Y`（含分割、删除、粘贴、裁剪/移动）

### 轨道（当前实现）
- 默认有视频 / 音频 / 字幕轨行；片段可拖到不同轨道
- **主剪辑**：按 `start_time` 排布；同轨波纹删除
- **叠层**：播放头下多视频轨可做简易上层叠加预览（非剪映级合成器）
- **音频**：视频内嵌音 + 独立音频轨 BGM（单轨混音预览）
- **字幕**：侧栏编辑 + 预览叠加；可随工程保存；导出时可烧录（需 FFmpeg）

## 快捷键

| 操作 | 快捷键 |
|------|--------|
| 播放/暂停 | Space |
| 分割片段 | S |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y |
| 保存项目 | Ctrl+S |
| 导出 | Ctrl+E |
| 导入素材 | Ctrl+I |
| 缩放时间轴 | Ctrl+滚轮 |

---

## AI 辅助

- **智能剪辑**：需 Ollama/算法可用时按提示词裁剪
- **字幕生成**：语音转字幕（需 ASR/Whisper 与 FFmpeg）
- **场景检测**：依赖对应算法模块是否可用
