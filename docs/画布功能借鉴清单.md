## 三、各产品核心功能速览

### ComfyUI —— 可控性天花板
- 节点式 DAG 工作流：全流程透明，模型/参数/步骤每环可见可调
- App 模式（简化视图）：同一工作流在"新手表单视图"与"节点图视图"间切换
- 社区工作流生态：6 万+ 节点、数千条共享工作流，一键加载
- 插件化扩展：ControlNet / IP-Adapter / ADetailer 等数百节点随意插入

### TapNow —— 导演级 + Agent 双端
- Tapflow 无限节点画布：脚本/分镜/图像/视频/音频全流程节点化，可复用可协作
- Agent 智能体 = AI 执行导演：自然对话驱动从角色设计到分镜编排
- 专业级镜头控制：模拟真实相机参数（ARRI ALEXA、焦段 18-200mm、光圈、景深），JSON 代码级提示词精准控制
- 一键拉片：上传参考影片 → 自动解析镜头语言/色调风格/景别 → 可编辑分镜表
- 角色/商品一致性：自研 Nano Banana 模型跨镜头保持外观一致
- TapTV 开源社区：百万级 TVC 广告完整流程开源，一键克隆二次创作
- 涂鸦生视频：手绘草图 + 文字 → 即时生成动态场景

### 即梦 AI（字节）—— 一站式 + 中文理解
- 智能画布：多图 AI 融合、分图层生成、局部重绘、一键扩图、消除、抠图，风格统一
- 首尾帧控制：首帧图 + 尾帧图输入 → 增强视频生成可控性
- 智能多帧运镜：最多 20 张图/片段 → 一镜到底长镜头 + 电影级运镜
- 故事创作模式：时间轨道插分镜，每镜头独立设风格/运镜/配乐，自动保持角色一致性
- @语法素材调度：提示词中 `@素材` 精准调度素材用途，提示词工程升维为"导演级调度"
- 动作模仿：单图 + 参考视频 → 精准复刻动作/表情/口型

### InvokeAI —— 画布 + 表单化工作流
- Form Builder（表单模式）：技术负责人搭复杂工作流，团队成员只填简化表单执行（参数锁定防呆）
- Canvas Output 节点：右键画布直接对图像跑工作流，输出成新图层
- 图层式编辑：Raster 图层 + inpaint mask 精确局部生成

### Krea AI —— 实时生成
- 实时生成 RTG：边画边渲染，<50ms 延迟实时预览（LCM 1-4 步推理）
- Pattern Tool：无限画布生成无缝纹理
- Logo Illusions：品牌 Logo 隐性嵌入画面

### Runway —— 视频精修
- Act-One：角色表演迁移（人脸驱动）
- Motion Brush：画面局部运动笔刷
- Gen-4 Turbo：精准相机/运动控制

### Infinite-Canvas（开源）—— 双模式 + 素材中枢
- 普通画布 / 智能画布双模式：节点编辑（高级）↔ 卡片式免连线（快速）
- 全局素材库：角色设定图/场景/风格样本跨画布复用
- 循环节点批量：基础参数固定 → 批量生成变体（表情/服装/背景）
- 多后端聚合：本地 ComfyUI / 云端 / 第三方 API 自由切换

## 四、共性强信号（优秀画布都在做的 5 件事）

1. **"节点画布 + 一键成片"双视图**：复杂流程可视化编排，但普通用户走简化入口（ComfyUI App 模式 / Infinite-Canvas 智能画布 / TapNow Agent 对话）
2. **分镜/拉片成为标配入口**：上传脚本或参考片 → AI 自动拆解成分镜节点（TapNow、即梦、LibTV 全都有）
3. **角色一致性是核心竞争力**：三视图 / Nano Banana / 故事模式角色锁定
4. **社区工作流开源复用**：TapTV / Comfy 模板库 / 即梦"做同款"——降低创作门槛的杀手锏
5. **AI Agent 双端接入**：CLI + Skill 包 + OpenAPI，Agent 一句话从剧本到成片
