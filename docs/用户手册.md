## 系统概述

ShortPlayAI Engine V1.0 是一款专为短剧制作设计的专业级视频编辑引擎，集成了先进的AI技术和插件系统。

### 主要特性

- 🎬 **专业级视频编辑**：支持多轨道编辑、5种编辑模式
- 🤖 **AI智能辅助**：场景分析、自动字幕、音乐推荐
- 🧩 **插件系统**：6个短剧专属插件，支持热加载
- 🎵 **音频处理**：BGM卡点、语音清理、变声、人声闪避
- 🚀 **高性能渲染**：软件/GPU/预览/导出多后端支持
- 📊 **性能监控**：实时性能监控和优化建议

### 系统要求

- **操作系统**：Windows 10/11, macOS 10.15+, Linux
- **处理器**：Intel i5 或 AMD Ryzen 5 及以上
- **内存**：8GB RAM（推荐16GB）
- **显卡**：支持OpenGL 4.0+（推荐NVIDIA GTX 1060及以上）
- **存储**：10GB可用空间
- **Python**：3.8+

## 快速开始

### 安装步骤

1. **下载安装包**
   ```
   从官方网站下载最新版本的安装包
   ```

2. **运行安装程序**
   ```
   Windows: 双击安装程序.exe
   macOS: 打开.dmg文件并拖拽到应用程序
   Linux: 解压压缩包并运行安装脚本
   ```

3. **首次启动**
   - 启动应用程序
   - 完成授权验证
   - 选择工作目录

### 基础操作

1. **创建新项目**
   - 点击"新建项目"按钮
   - 设置项目名称和存储位置
   - 选择视频分辨率和帧率

2. **导入素材**
   - 拖拽视频/音频/图片到素材库
   - 或点击"导入素材"按钮选择文件

3. **开始编辑**
   - 将素材拖拽到时间线
   - 使用工具栏进行剪辑、调整
   - 添加特效和转场

## 插件系统

### 短剧专属插件

#### 1. 金光特效（逆袭类）
- **功能**：逆袭时刻的金光特效，增强视觉冲击力
- **参数**：
  - 强度：0.0-2.0（默认1.0）
  - 颜色：自定义颜色选择
  - 持续时间：0.1-3.0秒（默认1.0秒）
- **适用场景**：主角逆袭、成功时刻、高潮片段

#### 2. 柔光特效（情感类）
- **功能**：情感场景的柔光特效，营造温馨氛围
- **参数**：
  - 强度：0.0-1.0（默认0.5）
  - 色调：自定义颜色
  - 模糊度：0-20（默认5）
- **适用场景**：温馨时刻、情感表达、浪漫场景

#### 3. 暗调特效（悬疑类）
- **功能**：悬疑场景的暗调特效，增强紧张氛围
- **参数**：
  - 暗度：0.0-1.0（默认0.5）
  - 对比度：0.5-2.0（默认1.2）
  - 暗角：0.0-1.0（默认0.3）
- **适用场景**：悬疑片段、紧张时刻、剧情转折

#### 4. 高亮特效（带货类）
- **功能**：带货场景的高亮特效，突出商品
- **参数**：
  - 亮度：0.0-1.0（默认0.3）
  - 饱和度：0.0-2.0（默认1.2）
  - 光晕：0.0-1.0（默认0.2）
- **适用场景**：商品展示、带货片段、产品介绍

#### 5. 淡入淡出转场
- **功能**：经典的淡入淡出转场效果
- **参数**：
  - 持续时间：0.1-3.0秒（默认0.5秒）
  - 缓动类型：线性、缓入、缓出、缓入缓出
- **适用场景**：场景切换、时间过渡、情绪转换

#### 6. 滑动转场
- **功能**：平滑的滑动转场效果
- **参数**：
  - 方向：左、右、上、下
  - 持续时间：0.1-3.0秒（默认0.5秒）
  - 模糊程度：0-10（默认2）
- **适用场景**：快速切换、动态过渡、节奏感强

### 插件管理

#### 安装插件
1. 打开插件中心
2. 点击"安装插件"或"导入插件"
3. 选择插件文件或从商店下载
4. 等待安装完成

#### 配置插件
1. 在插件列表中找到目标插件
2. 点击"配置"按钮
3. 调整插件参数
4. 点击"确定"保存配置

#### 启用/禁用插件
1. 在插件列表中找到目标插件
2. 点击状态按钮切换启用/禁用状态
3. 系统会自动重新加载插件

## 常见问题

### 安装和启动

**Q: 安装后无法启动怎么办？**
A: 请检查系统要求，确保满足最低配置。如果问题持续，请联系技术支持。

**Q: 授权验证失败怎么办？**
A: 请检查网络连接，确认授权信息正确。如问题持续，请重新获取授权。

### 编辑操作

**Q: 时间线操作卡顿怎么办？**
A: 尝试降低预览质量，关闭不必要的轨道，或升级硬件配置。

**Q: 导出视频失败怎么办？**
A: 检查存储空间是否充足，确认输出格式支持，尝试降低导出质量。

### AI功能

**Q: AI分析速度慢怎么办？**
A: AI分析需要一定时间，请耐心等待。可以尝试分析较短的片段。

**Q: 字幕识别不准确怎么办？**
A: 尝试提高音频质量，选择正确的语言，或手动编辑字幕内容。

### 插件系统

**Q: 插件无法加载怎么办？**
A: 检查插件版本兼容性，确认插件文件完整，尝试重新安装插件。

**Q: 插件配置后无效果怎么办？**
A: 确认参数设置正确，检查插件是否已启用，尝试重新加载插件。

### 术语表

- **时间线**：显示视频、音频等素材的时间轴界面
- **轨道**：时间线上的水平条，用于放置不同类型的素材
- **片段**：时间线上的单个媒体单元
- **关键帧**：标记属性变化的时间点
- **转场**：两个片段之间的过渡效果
- **特效**：应用到片段上的视觉或音频效果
- **渲染**：将时间线内容生成为最终视频文件的过程
