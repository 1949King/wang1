## 一、一句话战略

**该做**：把「从一句话到一条能播的片」这条链路的**可视化编排**（磁吸四向卡片）做成唯一差异化。

**不该做**：和剪映拼剪辑功能表、和 ComfyUI 拼节点连线、和大厂拼生成模型——这三件事必输，谁做谁死。

## 三、磁吸四向语义（该做的具体形态）

### 3.1 横向 = 时间 / 叙事主链（该做）

```
[意图胶囊] → [分镜脚本卡] → [首帧图卡] → [视频卡 / 伪真图卡] → [续接镜头] → …叠加拉长
   左            中              中            中 / 右              右
```

- **左 · 意图胶囊**：一句自然语言，点击解析 → 生成剧本脚本 + 场景分镜图。
- **中 · 分镜脚本卡**：承载文案 / 镜头描述，可编辑。
- **中 · 首帧图卡**：场景定妆帧（生图或伪真图）。
- **中 · AI 视频卡**：生成真视频片段；**伪真图卡**：静帧缓动，低成本铺时长。
- **右 · 续接**：串联下一镜头，往后叠加，总时长随需求拉长。

### 3.2 纵向 = 两条非时间维（该做，这是补全的重点）

- **上 · 全局导演控制卡**：分辨率／片段时长／整体画风／主角一致性／转场风格／BGM——「这一整条片子共用的设定」。
- **下 · 备选 / 素材卡**：同镜头 N 版备选、废弃候选、拖入素材、字幕稿——「往下堆备用材料」。

### 3.3 磁吸物理（该做）

- 贴边吸附、`gap = 0`（Windows 磁贴 / 手机桌面式），用卡片自身边框与内距做视觉分隔。
- **轴向优先级**：横向吸附优先（默认连成时间链），纵向是「挂载到某镜头」而非「串联」。

## 四、卡片功能模块清单（该做，逐卡定义）

| 方向 | 卡片类型 | 功能 | 输入 → 输出 | 状态流转 |
|---|---|---|---|---|
| 横·左 | 意图胶囊 | 自然语言启动 | 一句话 → 剧本脚本 + 分镜图 | 待解析 → 解析中 → 已出脚本 |
| 横·中 | 分镜脚本卡 | 承载文案 / 镜头描述 | 脚本 → 可编辑文案 | 草稿 → 已确认 |
| 横·中 | 首帧图卡 | 场景定妆帧 | 分镜 → 生成图 | 生成中 → 已出图 |
| 横·中 | AI 视频卡 | 真视频片段 | 首帧 + 提示词 → 视频 | 排队 → 生成中 → 已出片 |
| 横·中 | 伪真图卡 | 静帧缓动铺时长 | 图片 → 伪视频 | 合成中 → 已填充 |
| 横·右 | 续接卡 | 串联下一镜头 | 上一镜头 → 追加节点 | 空 → 已吸附 |
| 纵·上 | 全局设定卡 | 整片共用参数 | 参数 → 整片生效 | 折叠 → 展开编辑 |
| 纵·下 | 备选 / 素材卡 | 备选版本 / 素材收纳 | N 版 → 选中其一 | 备用 → 已启用 |

## 五、专业模式路线（该做 / 不该做）

| 决策项 | 结论 | 理由 |
|---|---|---|
| C 路线：一套骨架、两层深度（折叠=小白，展开=专业参数） | ✅ 该做 | 只有这条路「一套走天下」，不制造两套心智 |
| B 路线：小白磁吸 + 专业节点两套并存 | ❌ 不该做 | 双倍维护、用户切换即断层 |
| 完全照搬 ComfyUI 节点连线做编辑器 | ❌ 不该做 | 连线传数据不传叙事、粒度太细、无时间主链 |
| 磁吸模板复用（一组吸附卡片存成预设） | ✅ 该做 | 专业用户要的是「批量 / 复用」，这是刚需 |
| ComfyUI 只做「导出逃生舱」，不做编辑界面 | ✅ 该做 | 给硬核玩家留出口，又不污染小白主界面 |
| 让磁吸反向去学 ComfyUI 连线 | ❌ 不该做 | 本末倒置，会做成一坨四不像 |

## 六、避坑清单（明确「不该做」汇总）

1. ❌ 卡片间留空气间隙（破坏「挨得紧=是一组」的小白直觉）。
2. ❌ 四向同时强吸附、无轴向优先级（会把画布变成分不清主链的棋盘）。
3. ❌ 把伪真图冒充真视频进度（破坏「诚实失败」，长线留存崩）。
4. ❌ 一键出片做成「改不动的黑盒」（弃坑第一原因）。
5. ❌ 生成慢、排队无反馈（第二个弃坑点）。
6. ❌ 画布改完不能落进时间线 round-trip（断档即流失）。
7. ❌ 为堆卖点把 Agent 能力无脑全暴露（先接高价值，不接一次性噱头）。

## 七、P0 / P1 / P2 落点排序（该做的顺序）

- **P0（手感）**：四向语义定稿 + 贴边 `gap=0` 磁吸 + 轴向优先级。先把「挨得紧=有关系」立住。
- **P1（成片闭环）**：卡片类型注册表 + 15s 片段自动拼（首帧图 + 真视频 + 伪真图）+ 叠加拉长 + 入轨 round-trip。
- **P2（专业出口）**：展开态参数面板 + 磁吸模板复用 + ComfyUI 导出逃生舱。
