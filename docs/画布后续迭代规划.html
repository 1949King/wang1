1.2 最关键的执行事实：漂移 + 假闭环

本次真机 MD5 逐文件比对结果：两库 62 文件一致、16 文件漂移（与 P0-1 报告同数，但内容已变）。 更严重的是——本轮 AI 审阅的全部改动只落在 AI-Canvas-tauri/src/libtv，真源 shiguang-canvas/src 三个文件完全没跟上：bridge.ts（无 reviewCanvasNodeViaHost）、store.ts（无 reviewNode）、 App.tsx（无触发点）。磁吸内部还有 5 个文件（CardStack / FloatingToolbar / SoftConnectionLines / SpatialIndex / StackBadge）也发生了内容漂移。
AI 审阅目前是「假闭环」：前端 quality_scores 传空，后端按 70 基线打分并标注「估算」， 于是每张卡都返回「通过 · 70 分」。这违背项目一贯的「诚实失败」铁律（生图失败不写占位、口型无模型不写假片）。 在接入真实评分信号源之前，审阅接口只是「跑通了链路」，还没「产出可信结论」。

二、迭代点分级（P0 → P3）

级迭代点为什么动作
P0 立即 止血漂移 + 消灭假闭环 真源已落后，再叠功能只会越漂越远；「70 分假闭环」会把差异化卖点做成「假成功」口碑 启动 P0-1 抽包 Phase 0（16 文件分叉合并 + 依赖对齐）；五维评分接入可插拔信号源
P1 本波 抽包落地 + 评分做真 单一事实源是「不漂移」的根治手段；评分有了真信号才能宣发 P0-1 Phase 1–2（pnpm workspace + bridge 抽象注入）；评分接入 2 个便宜信号源
P2 下一波 空间叙事深化 + 三合一竖切 磁吸/意图胶囊/空间叙事是项目 memory 反复重申的三大差异化，至今只接了「壳」 一键整理布局接 SpatialAnalyzer；意图胶囊可选分支；「空间语义 → 分镜建议」闭环
P3 后置 边角能力按需 有需求再开，不抢主线 Form 参数锁定、Canvas Agent 完整、数字人口型、社区模板云、涂鸦/Krea（后两者明确不做）

三、四轨各自下一步（覆盖所有模块）

P 画布（差异化主战场）
① 五维评分做真：镜头时长（规则）→ 文案匹配（CLIP/语义）→ 画面质量（图像质量模型）→ BGM（节拍谱）→ 高光叙事（LLM）。接口已是 quality_scores 可插拔，只差信号源。
② 空间叙事深化：SpatialAnalyzer 接「一键整理布局」；意图胶囊支持可选变体分支。
③ 磁吸体验：磁吸开关/软连接已在 tauri 接线，回填真源补齐。
N 剪辑（手感地基）
① N1 继续拆 editor_module（AI 面板/属性页再抽 ≥1 模块），不卡主线。
② A4 涨分 8.5 收口。
③ B3 音乐卡点切镜（复用 B1 薄执行器，确认后写 _clips）。
④ round-trip 深化：入轨带 canvas_node_id + 字幕/时长元数据已通，做「画布改→剪辑回」双向。
A Agent（建议质量）
① 把五维评分接入 Agent：Agent 审阅画布卡片并给出「换镜/重生成」建议，而非只触发拉片/批量。
② 可撤销范围扩大：更多 editor.* 走公开包装 + Ctrl+Z。
③ 白名单与 capability 对齐说明持续更新。
D 数字人（诚实降级）
① 口型驱动继续诚实降级，等外部形象驱动模型，不烧资源造假片。
② 3D 导演台轻量增补：关节精调 / 更细摆姿（非整替换壳）。
③ 配比维持 ~10%，不主动扩大。

五、明确不做 + 硬门槛

  • 明确不做：WebDAV、整仓嵌 infinite-canvas/LibTV、浏览器直连 Key、Krea 实时、涂鸦生视频、完整 ComfyUI 宿主、Tauri 壳迁入、向量库万能 EDL（与既有口径一致）。

  • 诚实地基：任何「评分/审阅/成片」若没有真实信号源或模型，一律走「诚实降级 + 明文提示」，不写假成功——这是本项目区别于堆料产品的生命线。
