> 配套文档：`docs/安装与部署.md`（安装/出包/FAQ 事实源）、`docs/现行技术文档.md §40.20/§40.30/§40.31/§40.32`。

## 拍摄红线（先读）

1. **模型权重不随包、绝不自动下载**：凡涉及本地生成的镜头，必须先自取权重；未部署时只拍「诚实提示/降级」路径，不得冒充可用。
2. **RIFE 神经补帧权重（rife49.pth）当前未部署**：默认只拍 guidance 提示镜头；「真推理」镜头列为可选，需先按 §40.30 自取放置后才可拍。
3. **超分已改 RealESRGAN 本地优先 + 净 2x**（T2，§40.32），但权重未部署：默认只拍 guidance/降级双三次路径，口播不得称「RealESRGAN 超分可用」。
4. **四项对标优化已实施**（T1–T5，§40.32），但权重均不随包、网关默认关：只拍「诚实 guidance/降级」路径；真推理/网关全景镜头须先自取权重/自备网关，不得摆拍。注意：**当前 22:30 安装包不含四项优化代码**，入镜须重建含 T1–T5 的包或用开发态。
5. 可拍新能力：**全景真 3D 环视取景**（画布 📷 取景）、**神经补帧按钮 + guidance**、**转3D 按钮 + 3D 模型节点（guidance 路径）**、**局部语义三选（guidance 路径）**、生成后处理链的**音频保留 + 时序稳定**（依赖权重的镜头见分镜标注）。
6. 安装演示用**短目录**（如 `C:\拾光剪影`），四文件必须同目录；不要从 D 盘 dist 直接双击 Setup.exe（已知退出码 1 未定位，复制到 C 盘短目录即正常）。

## 分镜 0 · 开场（产品与两种形态）

- 画面：主界面全景（剪辑时间线 + AI 画布 + 数字人节点）。
- 口播要点：拾光剪影 = 本地优先的剪辑 + AI 生成工作台；两种安装形态——**全量**（含本地 AI 推理运行时，约 6.35 GB 安装内容）与 **Lite**（不含 AI 内核，约 529 MB 单文件，只用剪辑/画布）。
- 字幕：安装包**不含模型权重**，本地生成权重需用户自取（程序内给地址）。

## 分镜 1 · 全量安装

- 画面：资源管理器，四个文件放同一目录：
  `拾光剪影-Setup-4.47.0.exe` + `-1.bin` + `-2.bin` + `-3.bin`（总计约 2.05 GiB）。
- 操作：① 强调「四文件缺一不可、必须同目录」；② 可选演示 `Get-FileHash -Algorithm SHA256 <文件>` 对照文档 §2.9 哈希；③ 双击 Setup.exe → 许可页 → 目录选择改 `C:\拾光剪影`（短目录）→ 安装 → 完成页勾选桌面/开始菜单快捷方式。
- 口播要点：VC++ 运行时已随包（exe 根 + `_internal` 双份 CRT），干净机器**无需另装 redist**；安装目录保持简短，深层长路径会触发回滚（已知限制）。
- 标注：[可拍] 静默安装等价命令（字幕给出）：`Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR=C:\拾光剪影`。

## 分镜 2 · 首次启动

- 画面：开始菜单/桌面入口启动 → 主界面。
- 口播要点：首启做一次自检并初始化 `output\`、`logs\`、`短剧AI剪辑输出\` 等目录，比后续慢属正常；安装副本自检 26/26（Python 3.12.10，runtime 206 包 / 约 4.37 GB，torch 2.6+cu124）。
- 操作：快速巡览主界面、剪辑时间线、AI 画布、数字人节点（与开发态一致）。
- 标注：[可拍] 自检报告可用 `拾光剪影.exe --selftest --selftest-out report.json` 复现（字幕）。

## 分镜 3 · 模型自取（下载中心）

- 画面：程序内「本地模型面板」，每行「魔搭 / GitHub」链接。
- 操作：① 点开一行展示资源链接（ModelScope / GitHub，已核实可达）；② 命令行演示 `python scripts/check_models.py --missing` 看缺什么、怎么拿；③ 强调**软件不会自动下载任何权重**，用户主动下载后按面板指引放置。
- 口播要点：单个模型 12~85 GB 且许可各异，随包不可行也不合规；所以给地址、用户自取。
- 标注：[可拍] 工具权重已进下载中心（T1）：rife49 / ESPCN / RealESRGAN / LaMa / depth / Lightning LoRA 行可见，工具行「下载选中」禁用；`check_models.py --missing` 含工具段（缺什么 + 怎么拿）。

## 分镜 4 · 功能巡礼（已入包能力）

### 4a 剪辑与画布基础 [可拍]
- 画面：时间线剪辑操作、画布节点拖拽、数字人节点。

### 4b 全景真 3D 环视取景 [可拍]
- 画面：画布全景点 → 📷 取景 → 真 3D 球面环视（拖拽转向、滚轮变焦、俯仰限位）。
- 口播要点：three.js 内翻球面 + 真实相机视角，非 2D 平移；WebGL 不可用时自动降级旧 2D 视图（诚实降级）。

### 4c 神经补帧按钮 · guidance 路径 [可拍 · 默认]
- 画面：视频节点「🎞️神经补帧×2」→ 点击 → 弹出 guidance：资源地址（Google Drive / 百度网盘，MIT 许可）+ 四级放置路径（环境变量 SHIGUANG_RIFE_PATH / SHIGUANG_RIFE_DIR → thirdparty/models/rife49.pth → 模块目录）。
- 口播要点：权重未部署时**诚实提示自取**，不静默失败、不冒充成功。
- 可选镜头 [需先自取权重]：放置 rife49.pth 后重启画布桥 → 真推理补帧 ×2 → 产物落 inbox、源音轨保留；权重损坏/显存不足时降级光流并标 degraded。

### 4d 音频保留 + 时序稳定 [需生成权重 · 条件可拍]
- 口播要点：生成后处理链编码后自动 mux 源音轨（源无音轨/失败则保留无声产物＝天然回退）；时序稳定为光流 warp + 运动掩码的「时序稳定后滤波」，**不是时序超分模型**，口播不得夸大。
- 画面：需先自取生成权重跑一次生成才能展示产物；未部署时只口播原理 + 展示代码入口，不摆拍效果。

### 4e 超分画质 · guidance 路径 [可拍 · 默认]
- 画面：图像增强 high 档 / 视频超分入口 → 权重缺失时诚实提示自取（RealESRGAN BSD-3，qualcomm 仓地址）+ 降级双三次标注。
- 口播要点：T2 已接 RealESRGAN 本地优先 + 净 2x，但权重不随包；未部署只拍降级路径，不得冒充超分效果。
- 可选镜头 [需先自取权重]：放置 realesrgan_x4plus.onnx 后真超分 → 净 2x 产物对比。

### 4f 局部修改语义化 · 三选 [可拍 · 默认 guidance]
- 画面：蒙版编辑对话框 mode 三选（修补/移除/扩画）→ 权重缺失时 guidance（LaMa Apache-2.0 / SD1.5-inpainting OpenRAIL-M 副本随包）。
- 口播要点：默认 inpaint 走原路径零破坏；remove/outpaint 可选网关默认关；蒙版外像素逐字节不变是本地语义重绘的硬不变量。
- 可选镜头 [需先自取权重]：SD1.5-inpainting 目录放置后语义重绘真效果。

### 4g 图片转3D + 全景生成 [可拍 · 默认 guidance]
- 画面：图像节点「转3D」→ depth 权重缺失 guidance；3D 模型节点（NodePalette 自动出现）GLB 查看器；全景点「生成全景」→ 网关未启用 guidance + 常驻署名 "MiniMax H3"。
- 口播要点：转3D 产物是**深度重建 2.5D 网格（单图浮雕）**，非真体积/高斯泼溅，不得夸大；全景生成由可选网关 H3 提供、默认关、用户自备。
- 可选镜头 [需先自取 depth 权重]：真深度重建 GLB → 3D 节点环视；[需自备网关]：H3 全景生成 → PanoramaViewer3D 环视。

## 分镜 5 · Lite 边界与覆盖安装

- 画面：`拾光剪影-Setup-4.47.0-Lite.exe` 单文件（无 .bin）→ 安装向导。
- 口播要点：Lite 与全量唯一区别＝不含 `runtime` AI 内核；剪辑/画布/数字人/已配置云端能力一致；本地生图/生视频/神经补帧**诚实降级或提示不可用**。
- 操作：演示同 AppId 覆盖——全量 → Lite 覆盖时安装器自动清旧 runtime 残骸、**不碰用户作品与配置**；Lite → 全量覆盖补回内核。
- 标注：[可拍] 覆盖降级镜头会清掉演示机 runtime，拍完如需继续演示本地 AI 要再覆盖回全量。

## 分镜 6 · 卸载与数据保护

- 画面：控制面板「应用和功能」→ 拾光剪影 → 卸载。
- 口播要点：交互卸载会问「是否同时删除用户数据」，选否保留作品；静默卸载不询问、始终保留用户数据；只删三个明确目录（短剧AI剪辑输出/output/素材库）需用户明确同意，禁止递归删整个安装目录。
- 标注：[可拍] 卸载保护验收先例：`短剧AI剪辑输出\卸载保护验收.txt` 静默卸载后保留。

## 分镜 7 · 收尾 FAQ 速查

- 字幕卡（对应 `docs/安装与部署.md §五`）：
  - 提示缺 MSVCP140/VCRUNTIME140 → 装的是旧包或四文件不全，用新四文件重装（新包 CRT 已随包）。
  - 找不到 .bin → 四文件没放同目录。
  - 创建技能 SVG 失败回滚 → 目标路径过长，改短目录。
  - Lite 本地 AI 不可用 → 预期边界，需本地 AI 装全量。
- 口播收尾：所有功能与 TRAE 开发态一致；模型自取、诚实降级、绝不自动下载。
