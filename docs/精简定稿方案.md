# 拾光剪影 精简定稿方案

> 定稿日期：2026-08-01
> 定位：融合 Trae Work（AI IDE 架构）+ 剪映（专业剪辑底层）

---

## 一、产品定位

融合 Trae Work（AI IDE 架构）+ 剪映（专业剪辑底层）

1. **底层根基**：原生剪辑模块，独立完整可用，脱离 AI 也可全手动剪辑
2. **差异化核心**：独立全局主控 Agent，支持内嵌剪辑侧边栏/独立窗口双形态
3. **唯一交互入口**：Plan 模式，负责需求输入、方案撰写、任务审批、中途干预
4. **原生能力**：长期记忆/多线程并行/轨道随时打断均为软件原生能力；NAS 仅多主机协同选配

---

## 二、五层固定架构

### 第一层：底层地基·原生剪辑模块

视频导入解码、多轨道时间线、预览窗口、音频波形渲染、素材拖拽、工具栏绑定响应、片段分割拼接、转场、字幕、调色、变速；自带单机多线程渲染、工程保存、撤回回退、素材批量管理。所有 AI/CG 素材最终统一接入本模块轨道合成。

### 第二层：核心中枢·全局主控 Agent

- **双形态**：内嵌剪辑面板 / 独立窗口一键切换
- **长期记忆自主学习**：沉淀剧本、剪辑模板、素材风格、打分标准、用户修改习惯，数据默认存本地硬盘
- **全链路热插拔**：任意时间线/轨道/节点随时暂停、打断、局部重改
- **全局调度**：管控 Plan、拓展层、算力分配、自动化剪辑执行

### 第三层：交互入口·Plan 模式

全软件唯一需求输入通道，自然语言输入，自动划分三大业务并输出大纲、剧本、剪辑脚本、执行方案。**强制确权**：方案未手动确认禁止自动化执行；驳回则 Agent 重新生成。

**三大业务**：
1. 漫剧从零生成剪辑
2. 已有素材智能剪辑
3. Blender 3D/CG 短片制作

### 第四层：拓展赋能层

- **MCP 协议**：唯一对接 Blender，用于 3D 建模、特效、立体镜头渲染
- **插件池**：优先接入 LibTV 等漫剧云端生成工具，接入失败则自研
- **Skill 库**：导演 Skill、全自动剪辑 Skill，作为 AI 剪辑底层逻辑

### 第五层：算力支撑层（混合算力滑动调控）

算力构成：本地部署大模型（35B 及轻量化模型）+ 云端 API 订阅

**可视化滑动调节控件**（Plan 面板顶部快捷栏，区间 0%~100%）：

| 滑块值 | 逻辑 |
|--------|------|
| 0% | 100% 云端 API，本地模型完全休眠 |
| 50% | 默认出厂档位，本地/云端各 50% |
| 100% | 100% 本地大模型，断网可运行 |
| 任意值 | 自由拖拽，软件自动拆分负载配比 |

**智能自动适配**：
- 高负载任务（长视频渲染、3D 渲染、批量漫剧生成）→ Agent 建议调高本地占比（60%~80%）
- 文案构思、紧急快速出稿 → Agent 建议调高云端占比
- 断网状态 → 滑块自动锁定 100% 本地，联网后恢复自定义配比

**分工规则**：
- 云端 API：剧本大纲、提示词优化、创意构思、大批量草图生成
- 本地模型：画面精细化渲染、剪辑轨道运算、音视频推理、模型微调、成片细节优化

## 三、双记忆系统

### 核心定调

| 场景 | 适配模式 |
|------|----------|
| 连载长篇漫剧（几十~上百集、固定角色、统一世界观、长线伏笔） | 全局长期记忆 |
| 独立单集漫剧、50~60 秒 3D/AG 短片、零散短视频剪辑 | 便签临时记忆 + 短时特征缓存 |

两套记忆系统共用同一套技能沉淀库，AI 剪辑审美、纠错经验、高光判定规则全局互通。

### 模式 A：连载长篇漫剧 → 长期记忆

**存储内容**：
- 永久档案：角色外貌、性格、身份、世界观、主线大纲、核心禁忌设定，全程锁定
- 滚动剧情库：近十几集关键剧情、伏笔摘要（不存全部台词）
- 单集附属便签：本集临时镜头、高光、临时改动，仅本集生效

**运行逻辑**：剪辑单集时，优先读取全局角色档案 + 分集剧本 + 本集便签，兼顾长线统一与单集灵活调整。

### 模式 B：独立短篇/3D 短片/通用剪辑 → 便签记忆

**形态**：轻量化键值对便签，仅绑定当前工程

**存储内容**：
- 本集人物简短人设、3~5 条核心主线伏笔
- 已剪辑镜头清单、时间轴锚点、情绪标签
- 提前标记的高光点位、画面风格约束
- 中途修改指令、局部调整记录

**生命周期**：
- 新建工程 → 自动生成空白便签
- 剪辑全程 → Agent 随时读写，保证前后连贯
- 成片导出 → 默认直接清空销毁；仅提取本集优缺点/高光案例入库，原始脚本全部丢弃

### 模式切换规则

- 便签→长期：一键归档当前角色/设定到全局档案，转为连载项目
- 长期→便签：全局档案只读，仅生成临时便签做单集创作，不污染长线设定

**统一规则**：台词、分集脚本、临时镜头记录一律不长期入库；仅剪辑手法、高光打分、故障解决方案、风格参数存入公共技能库。

## 四、畸形/穿模/动作错乱根治方案（四层全链路闭环）

### 第一层：前置标准化约束

**角色骨骼生理约束库**：
- 为每个角色绑定固定骨骼 IK 约束模板，锁定肩、肘、腕、腰、膝等关节最大旋转角度
- 连载漫剧→存入全局永久档案；独立短片→临时写入本集便签
- 手部专项规则：单独锁定五指结构，强制指节分明、五指数量固定、手部不穿透面部/身体

**分镜文本规范化改写**：
- 错误：「男主抬手」→ 标准：「画面右侧手臂沿弧线缓慢抬起，肘部先行，手腕跟随，手掌自然张开，手部不接触脸部与躯干」
- 强制标注镜头景别、运动轨迹、道具位置

**首帧锚定机制**：
- 剪辑拼接：锁定前一段尾帧画面特征
- AI 生成：每段短片首帧固定绘制，后续画面必须对齐首帧人物样貌、体型、空间位置

### 第二层：生成过程实时管控

**AI 视频/3D 短片生成**：
- 强制开启 OpenPose/SMPL 人体关键点识别，AI 只能在骨骼框架内绘制
- 10~15 秒为最小镜头单元，上一段尾帧作为下一段首帧参考
- 内置 3 类安全转场模板（淡入淡出、动作衔接、镜头推拉），禁止无理由剧烈跳转

**剪辑轨道业务**：
- 素材拼接自动比对人物位置/动作走向，差值超标自动预警
- 裁切后锁定人物边界，禁止肢体残缺/错位

### 第三层：插帧补偿引擎（双模式）

**模式 1：轻量顺滑插帧（剪辑业务）**：两段素材拼接出现动作跳变，自动生成 5~15 帧过渡画面，不改动剧情/人物结构

**模式 2：逻辑搭桥片段生成（AI 生成业务）**：两段生成画面动作割裂，自动生成 0.2~2s 过渡小片段，读取骨骼约束+记忆系统人设，梳理动作因果

**通用**：所有插帧画面强制校验骨骼/手部结构，不合格直接丢弃重绘

### 第四层：AI 自动质检 & 局部修复

**三重自动化巡检**：
- 肢体巡检：手部畸形、肢体穿插、关节超限
- 逻辑巡检：动作与剧本匹配度、道具空间物理常识
- 时序巡检：镜头衔接、转场节奏

**分级修复**：
- 轻微瑕疵（局部手部错位）→ 局部重绘
- 严重畸变（整段动作崩坏）→ 标记作废，自动发起局部重生成
- 转场生硬 → 自动调用插帧引擎

**技能库联动**：所有畸形/翻车案例自动入库，AI 后续生成同类场景自动规避历史错误。

## 五、全链路完整执行流程

1. 用户在 Plan 输入自然语言需求
2. Agent 识别业务类型，输出完整执行方案脚本
3. 用户确认方案，同时按需拖动算力滑块设定配比
4. 算力层按配比分配云端/本地推理，拓展层产出素材
5. 素材导入底层剪辑模块，Agent 按脚本自动剪辑（全程插帧补偿+骨骼约束生效）
6. 执行全程可随时打断，切入轨道修改
7. 成片交付，用户精修定稿
8. 归档+发布，运营数据回流 Agent 迭代后续方案

---

## 六、硬性约束

1. 剪辑模块优先级最高，AI 仅为附加功能，软件可完全脱离 AI 使用
2. Agent 双形态自由切换，Plan 为唯一指令入口，自动化必须人工确认
3. 算力滑块可视化调控（0~100%），支持全云端/全本地/任意混合，默认 50:50
4. 全程支持轨道/时间线随时打断修改
5. NAS 仅多主机协同选配，单机无需
6. 自动剪辑逻辑依托 Skill 库，LibTV 优先外接，无法接入则自研
7. 畸变根治四层链路全闭环：前置约束→生成管控→插帧衔接→质检兜底

## 七、落地开发优先级

| 阶段 | 内容 |
|------|------|
| **短期（1~2 个月）** | 原生剪辑模块稳定落地；人体骨骼约束库 + 剧本标准化 Skill；插帧双模式升级；画面首尾锚定机制；便签临时记忆 + 公共技能库 |
| **中期** | 长期记忆模块（连载漫剧专用）；骨架姿态实时控制（OpenPose/SMPL）；自动化质检巡检 + 局部修复 |
| **长期** | 技能库持续积累迭代；向 L5 自主纠错/微调能力演进 |
