# 零基础学习路径与恶补计划（拾光剪影专用）

> 适用对象：**没有编程基础、没有 AI/视频技术背景**，但以「产品决策 + AI 执行」方式
> 接手本项目的人（含项目现在的负责人自己）。
> 目标不是把你变成程序员，而是让你**看得懂、敢拍板、能验收**。
> 架构事实一律以 [`docs/现行技术文档.md`](现行技术文档.md) 为准，本文只讲「怎么学、怎么练」。

---

## 0. 先认清一件事：你不学计算机科学，只学这个项目的 20%

一个 20 万行的项目，真正每天要碰的东西其实就这些：

| 你要做的事 | 需要的能力 | 不需要的 |
|---|---|---|
| 判断「AI 改得对不对」 | 会跑体检、会看红绿、会读报错 | 会写代码 |
| 提需求给 AI | 描述现象 + 贴日志 + 说清想要的效果 | 懂算法原理 |
| 拍板「做不做」 | 懂取舍（成本/收益/风险） | 懂实现细节 |
| 出问题时不被忽悠 | 知道去哪儿查、知道正常长什么样 | 会调试 |

**学完这份计划，你的定位是「懂技术的产品负责人」**——不是程序员，但没人能糊弄你。

## 1. 知识地图（5 大块，按优先级）

| 块 | 学什么 | 项目落点 | 学到什么程度就够 |
|---|---|---|---|
| ① 命令行基础 | cd / ls / 运行脚本 / 看输出 | 所有命令都在「接手速查卡」里 | **会复制粘贴 + 看懂在说什么** |
| ② Git 存档 | status / diff / log / commit | 每次改动前后存档 | 会看「改了什么」，会把改动存起来 |
| ③ Python 阅读能力 | 认得出变量/函数/import/缩进/打印 | `app/` 下 540 个 .py | **能顺着一个流程读下去**，不要求会写 |
| ④ 视频/AI 常识 | 分辨率/帧/编码/显存/扩散模型 | 生成与剪辑链路 | 听得懂名词，知道瓶颈在哪 |
| ⑤ 项目专有概念 | 真相源/冻结区/棘轮/守卫/bench | `docs/现行技术文档.md` | 能背下来（就 10 来个词） |

⚠️ 顺序很重要：**①②③ 是生存技能（1 周内必须会），④⑤ 是长期积累**。
很多人搞反了，先去啃「深度学习原理」——那是浪费时间，你不需要造模型。

## 3. 每天/每周固定动作（养成肌肉记忆）

**每天做完任何改动后（3 步，缺一不可）**：
```
1) 跑体检        → .venv312\Scripts\python.exe _verify\run_all_checks.py
2) 跑测试        → .venv312\Scripts\python.exe -m pytest app/tests -q
3) 存档          → git add -A && git commit -m "改了什么"
```
（Windows 下在项目根目录执行，前面加 `set PYTHONUTF8=1 &&` 或直接用 Git Bash）

**每周一次**：
- 看 `docs/CHANGELOG.md` 最新 3 条 —— 知道项目走到哪了
- 看 `.workbuddy/memory/` 最近 3 天的日志 —— 知道最近干了什么、踩了什么坑
- 备份一次整个项目目录（最朴素也最有效）

## 4. 必须背下来的 10 个概念（就这些）

| 词 | 大白话 | 为什么重要 |
|---|---|---|
| 真相源 | 唯一说了算的数据 | 改错地方等于白改 |
| 冻结区 | 「别碰」区域（107 把锁） | 碰了会弄坏老功能，且要走的流程很严 |
| 守卫 / 门禁 | 自动体检项（112 项 + 14 道卡点） | 它是你的安全带 |
| 棘轮 | 旧问题冻结，只许减不许增 | 防止「越修越乱」 |
| 回归测试 | 每次改完都重跑的全部测试 | 1,765 例，保护你不改坏东西 |
| bench | 性能实测脚本 | 用数字说话，不靠感觉 |
| 卸载( offload ) | 模型太大，分块换进显存 | 8GB 卡能跑大模型的唯一办法 |
| 诚实失败 | 做不到就明说，绝不放假结果 | 项目第一原则，你也用它来判断 AI |
| 双库 | 两套前端代码要保持同步 | 不同步会「分叉」，守卫会报 |
| 缺口记账 | 没做完的事记在案，不假装做完 | 防止「以为做完了」 |

## 附：与 AI 协作的正确姿势（比学技术更重要）

| ❌ 错误的问法 | ✅ 正确的问法 |
|---|---|
| 「帮我优化一下」 | 「生成图片要 30 秒，我想压到 20 秒以内，先给方案不动手」 |
| 「这里报错了」 | 「跑回归时这一项红了，完整报错如下：<粘贴原文>」 |
| 「继续」 | 「按规划第 7 章刀 A2 执行，完成后跑全门禁」 |
| 「这个好不好」 | 「对比方案 A（快但贵）和 B（慢但省），各自代价是什么」 |

**三个习惯**：① 让它先出方案再动手；② 要求附证据（文件 + 行号）；③ 改完必须跑门禁。
