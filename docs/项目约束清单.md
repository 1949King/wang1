## 1 产品定位约束（最容易被违反）
- 🔴 **定位 = 通用创意生产工具/创意工作台，不是「短剧剪辑工具」**。输入想法/素材 → 输出 图·视频·3D·成片；
  画布是工作台不是流水线。对标 Figma/Miro/Canva/ComfyUI/Runway/剪映。
  **禁止**拿「短剧」「懂短剧连续性」当定位与护城河；S0-S5 只是内置范式之一。
- 🔴 **本地优先，云端垫底**：能力默认本机跑通；云端只是兜底/加速（`app/core/ai/compute_bias.py`）。
- 🔴 **诚实原则**：不造假成功。"没测出来"≠"测出来了"；执行端不可用必须诚实失败（禁假音频/假产物）。
- 🔴 合规：AI 生成微短剧须在每集明显位置加标识（软件已内置角标+元数据，最终责任在发布者）；
  免责声明首屏只出现一次（版本升级才重弹），服务端记账不依赖 localStorage。

## 5 多会话并行协作纪律（本仓库常态）
- 🔴 提交一律**精确 pathspec**：`git commit -F msg -- <路径>...`；**禁 `git add -A` / `git add .`**。
- 🔴 **禁 `git commit --no-verify`**（本次会话曾误用一次，见文末"事故记录"；门禁必须真跑或明确记录原因）。
- 提交后核对 `git show --name-only HEAD`，确认没夹带别人文件。
- 暂存区是共享的：只 stage 自己的文件；混合文件（含别人未完成改动）→ 只加行内豁免、不代提，或按 hunk 部分暂存后说明。
- 门禁口径不一：ruff 看已暂存；`stability_gate`/`frozen_zone_guard` 全量扫工作区 ⇒ 别人的未提交文件能卡住你。
- 被卡住三步：核准 → 能独立成立就单独提交 → 不能就加豁免留给对方。
- `frozen_zone_guard.py --update` 是全量重写基线，会把别人正在改的冻结文件当前状态一起锁进去。

## 6 运行时/环境约束
- 🔴 **Qt6 WebEngine 必须给 `QApplication` 非空 argv**（空 argv ⇒ 渲染进程 0xC0000409 黑屏）；白屏另查 `QTWEBENGINE_CHROMIUM_FLAGS=--no-sandbox`；CSS 别用 `body:has(...)`。
- 🔴 PyQt6 别对 Qt 枚举 `int()`（TypeError 被吞 ⇒ console 零输出，用 `str(level)`）。
- 🔴 **启动必须优先 `.venv312`**（`C:\Python314` 有 PyQt6 无 torch ⇒ 本地模型全 `available:false`）。
- 🔴 **画布静态服务有 SPA 兜底**：缺文件返回 200 + HTML ⇒ 前端 ESM import 报 `Unexpected token "<"`；排查看 body 不看状态码。
- 🔴 QtWebEngine 右键菜单：**禁止在事件过滤器里 `exec()`/长期存活 `popup()`**（崩溃/黑块/假死）；现已默认关闭，右键走前端 React 菜单（`SHIGUANG_QT_CTX_MENU=1` 才启用 Qt 菜单）。
- 🔴 **清空 Qt 布局先 `hide()` 再 `setParent(None)`**：可见控件脱离父级会变成顶层窗口（实测一次搜索 583 个小窗）。
- 🔴 **WebEngine localStorage 不持久且 `setItem` 不报错**：跨重启状态必须服务端记账（`data/compliance_acceptance.json` + `/host/compliance/*`）。
- 🔴 Qt 页面验收两条腿：`QT_QPA_PLATFORM=offscreen` 验结构；真实窗口 `QTimer.singleShot` 后 `grab()` 验像素。QLabel 默认 PlainText（`**x**` 会原样显示）。
- 🔴 打包：目录扫描型子包必须进 `build_release.SYNC_APP_SUBPKGS`；`hiddenimports` 自动枚举；整目录拷贝必须排除 `.git`；`opentimelineio`/`mediapipe` 在冻结进程里加载即崩（OTIO 走子进程）。
- 🔴 SVD 图生视频输出尺寸必须随输入比例走（硬编码 1024×576 会横向拉伸 1.78×）。

## 7 UI 交互约束
- 🔴 浮动面板一律 `createPortal(..., document.body)`：`backdrop-filter`/`filter`/`transform` 祖先会成为 `position:fixed` 后代的包含块。
- 🔴 入口位置由能力归属层级决定，不由体积守卫有没有空位决定（工作区级能力挂常驻 `AppNav`）。
- 🔴 PyQt ↔ 画布唤起用「探测全局函数」不用 `dispatchEvent`（页面未加载也返成功）。
- 🔴 套接字错误码先查 `app/core/team_discovery.py`；错误码必须翻人话；`hostCall` 的 `authHeaders()` 放 `try` 外。
- 媒体交互（2026-11-13）：双击图片放大 / 双击视频播放；右键中文菜单（媒体：放大/收藏到我的资产/复制地址；空白：全选/刷新）。

## 8 验证与提交纪律
- **静态门禁全绿 ≠ 运行时没崩**；哈希 ≠ 不变量（新不变量须 AST 断言 + 反例验证）。
- A/B 对照必须逐轮换序（A/B/A/B 会让第二组恒定偏慢 3~5%）。
- 行尾：画布 `src/*.ts(x)`、技术文档、`frozen_zones.json`、`memory/*`、CHANGELOG = **LF**；`version.py`、`.mdc` = **CRLF**。
- 远程 origin 私有仓库；2026-11-12 实测 GitHub 不可达；推送前需历史手术（先别临场拼命令）。
