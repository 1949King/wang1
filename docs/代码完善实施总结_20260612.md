## 已完成的修复 (8项)

### 1. ✅ 密码安全升级 — `auth.py`
**问题**: 密码使用无盐SHA256哈希 (`hashlib.sha256(password.encode()).hexdigest()`)，极易受彩虹表攻击

**修复**:
- 引入 `bcrypt` (成本因子12) 作为首选哈希算法
- 实现 `_verify_password()` 方法，自动兼容三种哈希格式：
  - `$2b$...` — bcrypt（新标准）
  - `sha256$salt$hash` — SHA256+盐（中间格式）
  - 纯hex — 旧版无盐SHA256（向后兼容）
- **自动升级**: 登录验证时检测旧格式哈希，自动升级为bcrypt
- bcrypt不可用时降级为SHA256+随机盐（带warning日志）

### 2. ✅ JWT密钥安全 — `api_gateway.py`
**问题**: JWT密钥硬编码为 `"your-secret-key-change-in-production"`

**修复**:
- 改为从环境变量 `JWT_SECRET` 读取
- 启动时校验：未设置则输出 `RuntimeWarning`
- 新增 `import os` 用于环境变量读取

### 3. ✅ 命令注入修复 — `video_editing_skill.py` + `hardware.py`
**问题**: 
- `video_editing_skill.py`: `subprocess.run(cmd, shell=True)` — 文件名可注入命令
- `hardware.py`: 3处 `shell=True` 配合 `findstr` pipe

**修复**:
- `video_editing_skill.py`: 改为 `shell=False` + 参数列表
- `hardware.py`: 用 `Popen` pipe 替代 `shell=True`，添加输入白名单校验
- 两处均添加 `capture_output=True` 和 `CREATE_NO_WINDOW`

### 4. ✅ 插件安全沙箱 — `plugin_sandbox.py` (新建) + `plugin_system.py`
**问题**: `exec(plugin_code)` 直接执行任意插件代码，可导致任意代码执行

**修复**:
- 新建 `app/modules/plugins/plugin_sandbox.py`:
  - 白名单机制：仅允许安全的 builtin 函数（int/str/list/dict 等，共约50个）
  - 黑名单：禁止 `exec/eval/compile/__import__/open/globals/locals` 等
  - 危险模式检测：拒绝包含 `import os`、`subprocess`、`pickle` 等模式的代码
  - 大小限制：500KB
- `plugin_system.py` 修改：
  - `install_plugin()` 在执行前调用 `validate_plugin_code()` 安全扫描
  - 使用 `create_sandbox_globals()` 创建受限全局命名空间
  - 所有 `print()` 替换为 `logger`

### 5. ✅ OAuth令牌加密存储 — `oauth_qr_flow.py`
**问题**: OAuth令牌明文存储在 `oauth_tokens.json`

**修复**:
- 优先使用 `SecureStore` (Fernet加密) 存储令牌
- 加密文件: `oauth_tokens.enc.json`
- 自动迁移：检测旧明文文件时自动升级到加密存储
- 降级处理：加密不可用时回退明文（带warning日志）
- 裸 `except:` 替换为具体异常+日志

### 6. ✅ 登录安全加固 — `auth.py`
**问题**: 无登录失败限制、无会话超时

**修复**:
- 添加登录失败计数器：5次失败后锁定15分钟
- `_check_login_lockout()` — 检查锁定状态
- `_record_login_failure()` — 记录失败
- `_clear_login_failures()` — 成功登录后清除
- 线程安全的计数器（`_failures_lock`）
- 验证码 `print` 泄漏修复：只记录脱敏手机号

### 7. ✅ 资源泄漏修复 — 多处
**问题**: 数据库连接永不关闭、GPU线程池未清理、QThread泄漏

**修复**:
- **auth.py `AuthDatabase`**: 
  - 添加 `close()` 方法 + `atexit.register(self.close)`
  - 添加上下文管理器 `__enter__/__exit__`
  - 启用 WAL 模式和 foreign_keys
- **gpu_acceleration.py `AutoGPURenderer`**:
  - 添加 `__del__` 析构函数
  - 添加 `weakref.finalize` 确保回收
  - `atexit.register(self.shutdown)` 兜底
- **model_management.py**:
  - `TestWorker` 完成后自动 `deleteLater()`

### 8. ✅ 密码哈希统一 — `security.py`
**问题**: 两套独立的密码哈希实现（`auth.py` 无盐SHA256 vs `security.py` SHA256+盐）

**修复**:
- `PasswordHasher` 升级为 bcrypt 优先
- `hash()`: bcrypt (成本12) → SHA256+盐（降级）
- `verify()`: 兼容 bcrypt / sha256$salt$hash / salt:hash / 纯hex 四种格式
- `needs_rehash()`: 检测是否需要升级到bcrypt
- 修复 `except Exception: pass` 为具体异常处理
