## 1. 产品定位与北极星

### 1.1 是什么

**拾光剪影**是 PyQt6 桌面端「**短剧精剪 + AI 导演台画布**」。活路径只有两条：

- **剪辑模块**（时间线编辑、预览/播放、导出）
- **AI 画布**（导演台节点、生图/生视频、含智能体与画布数字人）

运营/发布、短剧筛选等已卸为**接口壳**，不再作为迭代主题。

### 1.2 北极星（当前）

> 竖切可重复：**导演台（含数字人）→ 分镜图 → 入轨精剪**。智能体只做「确认后执行」的遥控器，**不默认一键成片**。

### 1.3 四条专注轨（资源配比）

| 轨 | 配比 | 内容 |
|---|---|---|
| **N 剪辑** | ~30% | 时间线手感、建议入轨、冻结区回归 |
| **P 画布** | ~35% | `vendor/shiguang-canvas` 节点/落盘/诚实生成 |
| **A Agent** | ~25% | 白名单、确认后拉片/去水词/批量；剪辑↔画布 round-trip |
| **D 数字人** | ~10% | 画布 `digitalHuman` 节点（TTS+形象；口型成片有模型再接） |

### 1.4 明确不做

- 不重写时间线架构（真相源永远是 `EditorModule._clips`）
- 不换壳：Wails / OpenTake-Tauri 宿主 / tldraw 替换主画布 / Dify 当剪辑运行时
- 不默认「一键全链路成片」当主入口
- 不恢复短剧筛选/账号运营的功能体（仅保留接口壳）
- 不做 D1–D4（向量库 / 智能 B-Roll / 万能 EDL / 完整的转场库）

## 3. 架构分层与真相源

### 3.1 分层铁律

```
Application (main_qt6.Application)
  └── MainWindow + ModuleRegistry（懒加载 LEGO 模块）
        ├── ui_widgets / modules/lego    # UI：只负责渲染、交互、事件分发
        ├── app/core                    # 业务：数据、状态、渲染调度、AI 调用
        └── app/main_qt6.py             # 入口：调度
```

- UI 层不写复杂业务逻辑；core 层不写界面代码。
- 模块间优先 **EventBus**，避免硬依赖、跨模块硬编码。
- 状态（登录/权限/版本/用户）统一归集 auth/core 相关模块，禁止 UI 层乱放全局变量。

### 3.2 真相源

- **时间线真相源 = `EditorModule._clips`**。
- 禁用 `AppState`、孤儿 `ExportRenderer`（已清理，见[12-app_state](#附录)历史说明）。
- 轨索引用 `find_track_index_by_type`，禁止硬编码 `track == 1`。

### 3.3 双内核调度（`app/core/editor_scheduler.py`）

| 操作 | 倾向内核 |
|---|---|
| preview / probe | LIGHTWEIGHT（PyAV） |
| clip / export / multi_track / ai_clip | PROFESSIONAL（FFmpeg/MLT） |

### 3.4 渲染三级 fallback

```
RenderManager.render()
  ├─ ① C++ 引擎（NVENC/QSV/AMF 硬件加速）
  ├─ ② FFmpeg CLI（subprocess）
  └─ ③ CPU 回退（moviepy/纯计算）
       └─ 失败自动降级，需保留兼容回退
```

- 导出统一走 `RenderManager` + `editor_export`，禁止在 UI 里硬拼复杂 FFmpeg 命令。
- GPU 检测统一走既有 `GPUDetector`/`HardwareDetector`，禁止重复造硬件检测逻辑。

## 5. 冻结区（已修好功能锁死，禁改）

机器校验：`python scripts/frozen_zone_guard.py`（`--update` 重写基线）。

| zone-id | 标题 |
|---|---|
| `playback-av` | 时间线播放 · 音画同步（含 speed_ramp，已重锁） |
| `exit-media` | 关程序停声 · 防幽灵音频 |
| `clip-transform` | 归一化变换模型 |
| `transform-bake` | 变换关键帧导出 bake |
| `canvas-transform` | 预览画布变换交互 |
| `plugin-host-ui` | 插件宿主常驻 UI 入口 |
| `plugin-store-catalog` | 插件商店真实目录 |
| `stage3d-core` | 3D导演台 · 模型渲染与桥接（GLB/骨骼/材质/端口 18765·3011·3010/桥接） |

共 **8** 个 zone。改这些范围前必须先获用户「解冻 \<zone-id\>」，改完 `--update`。

**`stage3d-core`（3D导演台 · 模型渲染与桥接）锁点**（2026-08-20 冻结，`symbols=[]`，按整文件哈希锁定 7 个文件）：
- `bodyFigureUrl` 只返回 `bodychan.glb` / `bodykun.glb`（来自用户 blend 文件）
- `prepareBodyFigureMeshes` / `loadGLBRiggedHumanoid` 加载 GLB 后不覆盖、不替换原始材质与颜色
- 端口锁定：`canvas_bridge` **18765**、`canvas_runtime` 静态 **3011** / dev **3010** 不得改
- `export_vinchau_glb.py` 导出不改骨名映射、不改材质设置

锁定整文件（7 个）：`vendor/shiguang-canvas/src/{riggedHumanoid.ts, Stage3D.tsx, stage3dControlNet.ts}`、`app/core/{canvas_bridge.py, canvas_runtime.py}`、`app/modules/lego/character_management_module.py`、`scripts/export_vinchau_glb.py`。

**音画纠偏**：约 **280ms**（冻结），勿压回 80ms。

## 6. 发展方向与优先级（现行）

### 6.1 优先级总序（用户明确）

**先剪辑体验 → 再画布体验 → 再 AI 剪辑/智能体 → 再数字人口型成片。**

### 6.2 地基四层（自下而上）

| 层 | 目标 | 状态 |
|----|------|------|
| ① 敢动 | 清死代码 / 吞异常改日志 | ✅ 完成 |
| ② 不卡 | 预览/播放流畅（墙钟+顺序解码+音画同步） | ✅ 一轮完成；滤镜长片仍可能卡 |
| ③ 完整 | 接线 core（波形/关键帧/LUT/速度/多轨） | 大半完成；速度斜坡仍弱 |
| ④ 可维护 | 拆分 `editor_module` 上帝类（13,321 行） | **进行中**（详见 6.6） |
| 顶层 | AI 闭环接线 | 阶段 4–7 仅接口壳 |

### 6.3 剪辑体验（P0 剪映对齐）— 基本完成

主线：时间线 + 预览 ≈ 成片。

| 期 | 目标 | 状态 |
|----|------|------|
| 1 | 手感：波纹删除、吸附、trim/移动可撤销 | ✅ |
| 2 | 所见即所得：字幕烧录、转场近似、音量打通 | ✅ |
| 3 | 多轨：跨轨、双层合成、BGM、导出吃 start_time/track | ✅ |
| 4 | 深工具：speed、关键帧、EffectManager→预览 | ✅（速度斜坡仍弱） |

自我评分：日常短剧精剪约 **8.0 / 10**，目标 **8.5**。涨分队列：继续拆 `editor_module` → 少而真转场 → 长对白样片手测。

原则：非生成类 AI-NLE；AI≈80% 体力活；输出必须进 `_clips` 且可撤销；**竖切接入**（做一块接一块）。

## 7. 编码规范（浓缩）

- 命名：类大驼峰；方法/函数 `snake_case`；私有成员 `_` 前缀；常量 `UPPER_SNAKE_CASE`；变量见名知意。
- 导入：标准库 / 第三方 / 本地项目模块三段分组；优先 `from app.xxx`；禁冗余导入与循环导入。
- 分层：UI 只渲染；core 处理数据与状态；MainWindow 调度；不跨层硬编码调用。
- 注释：类与核心方法必须说明职责；关键逻辑加行内注释；不写废话。
- 异常：禁止裸 `except: pass`；必须记日志或给用户清晰提示；必填/格式校验、按钮防重复点击覆盖。
- 日志：core 用 `logger`，禁止裸 `print()`。
- 弹窗：必须绑定 `parent`；关闭后刷新父界面；耗时任务后台线程 + 信号回主线程更新 UI。
- 状态：登录/权限/版本/用户归 auth 模块统一管理。
- 修改原则：**最小侵入、最大兼容**；保留旧路径或 fallback；不擅删原代码、不私增无用文件。
- 验证：改 Python 后至少 `py_compile` 或对应测试；改导出/渲染后验证 C++/FFmpeg fallback。

## 8. 关键约定备忘

- 注册表 id 为 **`extensions`**（非旧 `plugins`）；`drama_finder`/`account_ops` 为插件接口壳，能力「诚实失败」。
- **诚实失败**：无模型/无 Key 时明文失败，不写假片、不占位图假成功（五维评分同样不得「假闭环」，见附录）。
- **五维评分**（100 分制）：画面质量 25 · 高光叙事价值 25 · 文案匹配 20 · BGM 适配 15 · 镜头时长合理性 15；分级 S≥90 / A≥80 / B≥70 / C≥60 / D<60，D 级默认剔除（全 D 走降级模式）。
- 联动音频片：导入视频自动生成音频双轨，BGM 同步时跳过。
- 墙钟播放：播放头用墙钟，不用 `+=0.033`。
