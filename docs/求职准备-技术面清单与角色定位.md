# 求职准备 · 技术面门槛清单与角色定位

> 用途：以拾光剪影为敲门砖求职 AI 相关岗位时，**要面对的技术面有哪些、怎么补、你的角色怎么说**。
> 配套：[`零基础学习路径与恶补计划.md`](零基础学习路径与恶补计划.md) · [`接手速查卡.md`](接手速查卡.md)
> 原则：**不吹不黑**——把真实做过的东西翻译成面试语言，把没做过的如实标为「正在补」。

---

## 第一部分 你的角色怎么说（最重要，先把这条定下来）

### 你的真实分工（据本人自述）

| 你负责 | AI 负责 |
|---|---|
| 需求定义（要做什么、给谁用、什么算好） | 代码实现（写文件、改文件） |
| 产品设计（流程、界面、交互、闭环设计） | 算法细节（扩散推理、显存策略参数） |
| 功能拆解与优先级（先做什么、后做什么） | **部分**架构方案的产出 |
| 关键技术取舍**拍板**（做不做、用哪条路） | |
| 验收标准与全流程验证（跑门禁、判红绿） | |
| 工程纪律建设（冻结区/守卫/棘轮/诚实失败） | |

### ✅ 面试推荐表述（照这个说）

> 「这个项目我是**总设计和决策者**：需求、产品闭环、功能拆解、验收标准、关键技术取舍都由我定；
> 代码实现和算法细节我用 AI 作为执行工具完成。
> 为了保证 AI 改东西不出错，我建立了一套验证体系——726 个自动化测试、62 项一键体检、
> 9 道提交卡点、85 个冻结锁。**AI 负责写，我负责判断和把关**，这也是我认为面向 AI 时代
> 最有效的工作方式。」

### ⛔ 千万别说的两句话

| ❌ 不要说 | 为什么 |
|---|---|
| 「代码都是 AI 写的，我不太懂」 | 直接把自己判成 0 价值，面试官不会再问下去 |
| 「这是我独立开发的」 | 一旦被追问细节就穿帮，诚信是红线 |

### 💡 这句话术为什么强

它同时传递了三个信号：**① 有产品与架构判断力 ② 有工程管理能力（能建体系） ③ 掌握 AI 时代的新型生产方式**。
第三个在 2026 年恰恰是很多团队想招而招不到的能力。

## 第二部分 技术面全景清单（按优先级，照这个补）

### 🔴 P0 = 必考，不补过不了技术面

| 主题 | 具体会问什么 | 项目对应点 | 补法 | 验收标准 |
|---|---|---|---|---|
| **Python 基础** | 数据类型/列表字典/函数/类/异常/文件读写/虚拟环境 | 全项目的语言 | 菜鸟教程 + 动手改小脚本 | 能读懂项目里任意一个 200 行文件 |
| **数据结构与算法（入门级）** | 数组/字符串/哈希表/栈队列/排序/双指针/二分 | `_verify/` 里的脚本逻辑 | LeetCode 简单题 + 中等前 100 题 | 能独立做出简单题 |
| **Git** | 提交/分支/回退/解决冲突 | 项目日常 | 廖雪峰 Git（前 4 节） | 敢改敢撤不怕手滑 |
| **HTTP 与接口** | 请求方法/状态码/REST/JSON | 项目 83 个 `/host/*` 接口 | 看项目接口清单 + 用 curl 试 | 能解释一个接口的输入输出 |
| **测试基础** | 单元测试/断言/覆盖率/mock | 726 个 pytest | 读 `app/tests/` 任选 3 个 | 能自己写一个简单测试 |

### 🟠 P1 = 大概率考，决定能不能过中级岗

| 主题 | 会问什么 | 项目对应点 | 补法 |
|---|---|---|---|
| **并发编程** | 线程/进程/锁/为什么加锁 | `EditorModule._clips` 的 RLock、「跨线程共享必须持锁」 | 学「锁」这一章，讲清项目里为什么加 |
| **性能分析** | 怎么找瓶颈/怎么测 | 冷启动 55s→1s 优化史、四档显存实测 | 读 `docs/冷启动性能诊断报告.md` |
| **数据库基础** | SQL/索引/事务/缓存 | 项目用 JSON 持久化 + 缓存系统 | SQL 基础 30 题 + Redis 概念 |
| **Linux 基础** | 常用命令/进程/权限/日志 | 项目有 Docker 配置 | 掌握 20 个常用命令 |
| **Docker 入门** | 镜像/容器/部署 | `Dockerfile.local` | 会写一个最小 Dockerfile |

### 🟡 P2 = AI 岗专属，你的差异化优势（重点准备，容易得分）

| 主题 | 会问什么 | 你的项目实据（能摊开讲） |
|---|---|---|
| **推理优化 / 显存管理** | 显存不够怎么办/量化/offload | **8GB 显卡跑 6.46GB 的 SDXL**：四档实测（whole/model/sequential/layer），定稿 model_offload 5.21GB/27.9s |
| **扩散模型基础** | 文生图原理/步数/CFG/seed/采样器 | 双栈引擎（DiffSynth + diffusers）落地与对比 |
| **Prompt 工程** | 怎么写提示词/负面词/结构化 | 角色提示词构建、意图卡片体系 |
| **模型部署** | 权重格式/加载/离线/依赖管理 | 全离线加载三件套（解决代理 502 三连炸） |
| **Agent / 工具调用** | Agent 怎么调度工具/如何不跑偏 | 72 个能力的单一事实源目录 + 白名单 + 建议确认后写入 |
| **多模态链路** | 文→图→视频→音频→成片 | 完整闭环已跑通（生成→入轨→剪辑→导出） |
| **模型评测** | 怎么判断生成质量 | 代理评分器 + 账本 + 抽检冻结机制 |
| **RAG / 向量库** | 检索增强 | ⚠️ 项目里没有——**如实说「了解概念，未实践」** |

### ⚫ 明确不补（会浪费你 200 小时）

算法竞赛、编译原理、分布式共识、CUDA 编程、Transformer 数学推导、大模型训练/微调实战。
→ 这些是研究岗与 infra 岗的考点，与你要投的「AI 应用/产品/解决方案」方向无关。

## 第四部分 这个项目会被深挖的 20 个问题（附答题要点）

### A. 产品与决策类（你的主场，必须答满）

| 问题 | 答题要点 |
|---|---|
| 这个项目解决什么问题？ | 一句话+一句话场景：一人做短剧的「想法→成片」全链 |
| 为什么先做剪辑不做 AI？ | 剪辑是日产工作量最大、确定性最高的环节；AI 生成不确定，先把确定性打牢 |
| 项目的技术路线怎么定的？ | 先稳→快→全→可维护；AI 闭环放后面，避免地基不稳 |
| 如果只能保留一个功能，保留哪个？ | 论点：时间线主线（因为它是所有 AI 产物的落地口） |

### B. 工程与架构类

| 问题 | 答题要点 |
|---|---|
| 为什么建「冻结区」？ | 修好的功能不能被无意改坏；85 把锁 + 守卫自动拦 |
| 726 个测试怎么来的？有意义吗？ | 核心路径全覆盖；保护「改 A 坏 B」这类回归 |
| 你怎么保证 AI 改的代码是对的？ | 三道：需求拆解定验收 → 跑全门禁 → 冻结区+棘轮防退化 |
| 单文件 9700 行怎么不重构？ | 承认是技术债，正在按 mixin 拆分（有量化拆分方案） |
| 为什么有 62 项自研体检而不是用现成工具？ | 查的是「项目语义」（如路由可达性、字段六处同步），通用工具查不出 |

### C. AI 与算法类（准备 3 个深度故事）

| 问题 | 答题要点（数字要能背） |
|---|---|
| 8GB 显存怎么跑 SDXL？ | 四档实测：whole 卡死 / model 5.21GB 27.9s（定稿）/ sequential 3.76GB 61.6s / layer 3.96GB 72.7s；用 offload 分块换入换出 |
| 你说的「五次反转」是什么？ | 一次测量被僵尸 CUDA 状态污染，误判模型不可用；受控复测证伪 ⇒ 建立了冷却+遥测+硬杀后作废的测量纪律 |
| 怎么判断生成质量？ | 代理评分器（只筛可证伪的坏，红线 is_proxy）+ 账本记录 + 人工抽检冻结 |
| 为什么做双引擎主备？ | 避免单点依赖；主选不满足时自动降级且**降级必须可见**（R9） |

### D. 反向问题（面试官爱问）

| 问题 | 答题要点 |
|---|---|
| 项目最大的不足是什么？ | 前半链缺（编剧/美术资产无真值）+ 成果没全接通用户——**已列成路线图在推** |
| 重做会怎么改？ | 先定数据契约再写功能；评测自动化再上线 |
| 你最大的短板？ | 编码基础与算法（正在补，给具体进度）；**不装懂** |

## 第五部分 面试避坑

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 把「AI 写的」说成自己的 | 追问即穿帮，诚信归零 | 明确说分工，强调你的判断与把关 |
| 死背名词但说不清为什么 | 一问细节就露怯 | 只讲你真做过的，每个数字都要能解释来源 |
| 被指出不足就辩解 | 显得不成熟 | 大方承认 + 说明已列计划（有规划报告为证） |
| 只讲技术不讲业务 | 产品岗会觉得没商业感 | 一半时间讲「给谁解决什么问题」 |
| 夸大规模骗面试官 | 有经验的面试官一眼识破 | 22.8 万行、726 测试这些**真实数字**足够打动人 |

## 第六部分 一句话总结

**你的敲门砖不是「我会写代码」，而是「我能把 AI 组织起来，把一件复杂的事做成，并且保证它不出错」。**
这个定位在 2026 年的 AI 应用岗位上，比「会背八股」更稀缺——但**基础题该刷还得刷**，否则进不了技术面。
