# 15 — 长期迭代计划（自动执行轨）

> 制定日：2026-08-12  
> 原则：竖切可演示；最小入侵；不换 `_clips`；不嵌商业 LibTV；配比延续季度主题。  
> 执行约定：每完成一波 → 更新本表状态 + [`05-known-issues.md`](05-known-issues.md) + 必要时 `npm run build`。

**漫剧「导演台 → 分镜图 → 入轨精剪」可重复竖切**，体感接近 LibTV 工作流，剪辑地基继续涨到自评 **8.5**。

## 硬边界（全程）

- 不重写时间线；轨索 `find_track_index_by_type`
- 不换壳（Wails / OpenTake / tldraw 主 UI / 整仓嵌入 LibTV）
- 不默认「一键全链路成片」
- 对话框有 parent；模块间优先 EventBus
- 改冻结区前先解冻 [`08-frozen-zones.md`](08-frozen-zones.md)

## 自动执行节奏

1. 打开本文件「当前波」任务 → 改代码 → build → 更新状态  
2. 一波全部 ✅ 后把下一波标为「执行中」并继续（同会话或 handoff）  
3. 阻塞（缺 Key / API 不支持）→ 降级路径 + 状态条诚实说明，不卡整波
