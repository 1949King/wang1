## E. 季度主题：漫剧剪辑主轴 + Agent 遥控器（2026-08 决策）

> 资源配比：**剪辑/漫剧 ~70% · Agent 遥控器 ~20% · 闭环收口 ~10%**  
> 不另起架构；不承诺「全局总控一键漫剧成片」。  
> 对外叙事：**短剧/漫剧精剪工具 + AI 体力活助手**。

### 硬门槛（未达则不加大总控投入）

- [ ] 日常精剪自评稳定 ≥ **8.0**（对照 `00-overview` 评分表）
- [ ] Dispatcher 至少 **8** 个真能改 `_clips` 且可撤销的 `editor.*` / 等价能力
- [ ] 一条可重复演示竖切：对白样片 → 去水词/切静音 → 人确认 → 成片

### 里程碑（6 条，可验收）

| ID | 配比 | 主题 | 做什么 | 验收标准 | 预估 |
