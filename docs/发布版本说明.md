## 安装方式

### 方式一：安装包安装

#### Windows
1. 下载 `ShortPlayAI_Engine_V1.0.0_Windows.exe`
2. 双击运行安装程序
3. 按照安装向导完成安装
4. 启动应用程序

#### macOS
1. 下载 `ShortPlayAI_Engine_V1.0.0_macOS.dmg`
2. 打开DMG文件
3. 将应用程序拖拽到应用程序文件夹
4. 启动应用程序

#### Linux
1. 下载 `ShortPlayAI_Engine_V1.0.0_Linux.tar.gz`
2. 解压压缩包
3. 运行安装脚本：`sudo ./install.sh`
4. 启动应用程序

### 方式二：源码安装

```bash
# 克隆代码仓库
git clone https://github.com/shortplayai/engine.git
cd engine

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/macOS
# Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 运行应用
python main_qt6.py
```

## 已知问题

### 当前版本已知问题
1. **Whisper模型加载**：在部分Windows系统上可能遇到DLL加载问题
   - 临时解决方案：使用CPU版本或更新CUDA驱动
   - 计划修复：V1.0.1

2. **GPU渲染**：部分AMD显卡可能存在兼容性问题
   - 临时解决方案：使用软件渲染
   - 计划修复：V1.0.2

3. **大文件处理**：处理超过2GB的视频文件时可能出现性能下降
   - 临时解决方案：使用代理预览
   - 计划优化：V1.1.0
