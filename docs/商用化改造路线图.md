## 一、与同类开源项目对比结论（摘要）

本项目是 **AI 自动剪辑编辑器**，同赛道可比项目分两类：

| 项目 | 语言/框架 | 定位 | 架构 | AI能力 | 商用就绪 |
|------|----------|------|------|:--:|:--:|
| **拾光剪影** | Python + PyQt6 + MLT/FFmpeg/C++ 引擎 | AI 全流程剪辑 | 四层隔离+事件总线+冻结区 | ★★★★★ | ★★☆ |
| Shotcut | C++/Qt + MLT | 通用 NLE | 成熟稳定 | ★ | ★★★★ |
| Kdenlive | C++/Qt/KDE + MLT | 通用 NLE | 成熟 | ★ | ★★★★ |
| OpenShot | Python + libopenshot(C++) | 易用 NLE | 动画框架强 | ★ | ★★★★ |
| FunClip(阿里) | Python + FunASR + Gradio | 语音切片 | 模块化 | ★★★★ | ★★★ |
| autocut(trsdn) | Python + Parakeet | 确定性剪切 | 工程化好、功能窄 | ★★★ | ★★★ |
| OpenCut | TypeScript/Rust 重写 | 开源"剪映" | 愿景 > 落地 | ★ | ★★ |

**结论**：拾光剪影在 **AI 能力（ASR/LLM/五维评分/BGM/AIGC/Agent）是断层领先**，工程纪律（四层隔离/冻结区/门禁）也优于同类 AI 工具。**唯一短板是"能卖"的收尾项**——安全合规、代码签名、安装器、测试覆盖。本项目当前最接近"打包直接发布"，差距已从旧文档的"38个问题"收敛到少量收尾项。

### 3.1 防破解落地方案（PyArmor 调研结论）

> 2026-08 调研：PyArmor 8.x 是当前 Python 打包混淆的主流方案，官方中文文档完善、与 PyInstaller 集成成熟。

| 许可 | 含税价 | 解锁能力 | 适用本项目 |
|------|-------|---------|:--:|
| 试用版 | 免费 | 功能受限：不能加密大脚本、不可用 RFT/BCC、不可商用 | 仅内部验证 |
| **基础版** | ¥359 | 大脚本 + 字符串混淆 + 商用 | ✅ |
| **专家版** | ¥562 | 基础版 + RFT/BCC 不可逆加密 | ✅ 推荐 |
| 集团版 | ¥918 | 专家版 + 离线加密 + 无限制 Docker | CI 离线时用 |
| 管线版 | ¥569/年 | CI/CD 环境专家版功能 | 需全自动构建时用 |

**推荐落地路径（专家版）**：

```bash
.venv312\Scripts\pip.exe install pyarmor
# 1. 注册授权（购买后官方邮件发来 regcode 文件）
.venv312\Scripts\pyarmor.exe reg pyarmor-regcode-xxxx.txt

# 2. 混淆核心代码（生成 obf/ 后与 PyInstaller 打包）
.venv312\Scripts\pyarmor.exe gen --pack dist\拾光剪影\拾光剪影.exe app\main_qt6.py
# 或先混淆再打包：
.venv312\Scripts\pyarmor.exe gen -O obf -r app
```

**注意**：
- 本项目 370 个 Python 文件、14.78 万行，试用版**无法**加密大脚本，必须至少购买**基础版**；推荐**专家版**（RFT/BCC 模式抗反编译更强）。
- RFT/BCC 模式会显著增加混淆耗时与包体积，且对 `exec`/`pickle`/动态导入有兼容性要求，需在打包后全量回归。
- 混淆后需叠加**完整性校验**（启动时校验关键 .pyc/.pyd 哈希）+ **反调试**（检测调试器附加）构成纵深防护。
- PyArmor 许可证按"一个产品一个许可证"，运行端无需安装 PyArmor、不校验许可。

## 四、打包直接发布操作手册

```bash
# 1. 安装依赖（含新安全依赖 bcrypt/cryptography）
.venv312\Scripts\pip.exe install -r app\requirements.txt

# 2. 打包 onedir（项目根目录执行；spec 内 exe/COLLECT 名已统一为「拾光剪影」）
.venv312\Scripts\pyinstaller.exe app\ai_video_editor_local.spec --noconfirm
# 产物: dist\拾光剪影\拾光剪影.exe

# 3. 生成安装器（已新增 scripts/installer.nsi）
makensis.exe scripts\installer.nsi
# 产物: dist\拾光剪影-Setup-4.10.3.exe

# 4. 代码签名（发布前，需 EV 证书）
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a dist\拾光剪影-Setup-4.10.3.exe
```

启动时 `main_qt6.py` 会调用 `secure_store.upgrade_pii_files()` 将凭证/会话升级为 `.enc.json`。
